# README images

`openmeld-demo-light.jpg` is a browser screenshot of the landing page's
interactive product demo, captured on October 13, 2026 at 1512 × 806 pixels.
It uses the demo's native light theme and fictional sample content.

To refresh it:

1. Open [the Conversation demo in light mode](https://openmeld.ai/product-demo/?scene=Conversation&theme=light).
2. Keep the initial conversation, Thread, and Members panels open. Wait for
   fonts and avatars to load and the initial composer highlight to finish.
3. Capture the full demo viewport as a JPEG and replace the image.
4. Check the image in the repository README preview.

The demo reuses product components. Its source and build instructions are in
[the website capture guide](../../clients/web/scripts/website-capture/README.md).
See [avatar sources](../../clients/web/scripts/website-capture/avatars/SOURCES.md)
for the sample portraits.
