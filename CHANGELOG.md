## September 15, 2026

### Bring Agents into a conversation with clearer mentions

Fixed · agents · spaces

Sending only an Agent mention now carries relevant preceding conversation and
attachments, so an Agent can understand a request sent just before the mention.
Explicit quotes take priority, and recalled messages are excluded.

Agent messages show their selected recipients even when their names are absent
from the prose. Center Agent final replies and Space Routine reports can include
explicit Human Mentions that use the same notifications as other Space messages.
Plain names do not create notifications or wake another Agent.

Evidence: pr:1068, commit:b96b139292217db0bcd1a86c2604b0c99349ca91, workflow:34941004106

### Check Agent usage before sending a Wake

Fixed · agents · spaces

Agent cards and profile pages show teammates' reported remaining usage and
reset times. The mention picker and composed Agent mentions show a usage
preview, and selecting a composed Agent name opens its profile card. Teammates'
cards also include an arrow to their full profile; owners keep the edit shortcut.
Unavailable usage stays unknown, and older observations stay marked as stale.
When a reported limit prevents a Wake, the Composer shows the known reset time
next to the existing status. Quota failures state the reason in the conversation;
message details show current reset guidance without changing the recorded outcome.

Evidence: pr:1068, commit:b96b139292217db0bcd1a86c2604b0c99349ca91, workflow:34938662680

### Easier, faster access to Thread replies

Improved · spaces

Thread previews open across the whole reply row and show the latest replies,
authors, and times. New Threads appear when their first reply arrives. Message
loading has a visible indicator, and previews and restored panels warm their
messages before opening.

Links from Agent conversations locate the message shown in the preview. Explicit
Thread links begin loading their messages alongside the Space, and show the
Thread loading panel while access and conversation data are being checked.

Messages in Spaces, Threads, and direct messages become read after their
beginning stays visible briefly. Long replies no longer require scrolling to the
end, and unseen messages and closed Threads keep their unread indicators.

Agent progress follows the selected reply destination. Completed replies in a
Thread also clear stale progress in the main conversation.

Evidence: pr:1070, commit:c1c13deed77ad26b20c86fa2978de14b05b919d6, workflow:34938662680

### More reliable computer connections and recovery

Fixed · v0.3.206 · service · computers · wakes

Temporary credential-store delays no longer disconnect a working computer, and
switching Organizations keeps the same local connection. When a connection is
interrupted, OpenMeld resumes retries as soon as credentials are available and
gives running work more time to reconnect without starting it again.

Your computer's Connection history shows recent interruptions and automatic
recovery. Private, limited diagnostic summaries upload after reconnection to
help explain what happened without sharing chat content or credentials.

Evidence: pr:1051, pr:1055, workflow:34902801271, commit:ca92fef004ea00bc726f34015ba1ae2e9ba0cbda

### More reliable Computer setup and recovery

Fixed · v0.3.200 · computer · cli

Computer setup requests a macOS background Service start without restarting an
already running Service. Startup failures retain diagnostic details, and CLI
update and diagnostic commands remain available when an earlier connection
cannot recover.

Setup also migrates original local agent settings without requiring a reset.
An older npm installation that cannot update no longer blocks setup through
the new managed OpenMeld binary.

When setup starts a background Service update, it waits for that operation and
continues automatically instead of asking you to run setup a second time.
It verifies the running Service before continuing. If Terminal closes after the
update begins, the background worker finishes the same setup and Web updates
automatically when the computer is connected.

Web onboarding keeps an active Terminal connection flow in place while computer
status refreshes, so a successful connection can finish in the same flow.

On macOS, starting a stopped Service also re-enables its automatic update worker
before registering it, avoiding a startup failure caused by its disabled state.

### Coordinate local development across worktrees

Improved · v0.3.198 · developer-workflow

Isolated development servers and broad validation commands now coordinate local
resource capacity across worktrees. Startup waits when memory is constrained,
status includes descendant processes and memory usage, and shutdown verifies
