## August 19, 2026

### Collapse sidebar groups when you need more room

Improved · navigation · web

The main sidebar now groups People, Agents, and Computers under Team and lets
you collapse Work, Team, and Resources. OpenMeld remembers those choices as you
move between pages, while compact sidebars keep every destination available.

Evidence: pr:119, commit:f56c4a77ef59c5d2e9d48533d794145fb868aa75, workflow:32198069001

### Open exact Slack messages from Inbox

Fixed · inbox · slack · center-agent

Inbox now links Center Agent Slack updates to the exact Slack message. Opening
the link marks the OpenMeld item read, and temporary Slack permalink failures
are retried without creating duplicate Inbox items. Existing Slack items are
upgraded in place without resetting their read, action, or dismissal state.
Tabs left open during the rollout keep the prior Center Agent destination until
they reload the current Web client.

Evidence: pr:124, commit:03339b2fad85e6bb2834ee9085ad0ddbdef59f88, workflow:32190997197, workflow:32197280409, workflow:32198069001, workflow:32198451108

### See the same Computer status everywhere

Fixed · computers · web

Computer cards, detail pages, and navigation now use the same status and
attention color. An available update stays amber everywhere, while required
repairs stay red and Computer details keep one clear OpenMeld Service action.

Evidence: pr:133, commit:e61d981b0d248a00498f3ca34c8e2cf486b536e4, workflow:32209316256
