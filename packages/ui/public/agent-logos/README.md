# Agent brand assets

`grok-bot.png` is the official Grok Bot application mark, extracted without
alteration from the installed Grok Bot macOS application's
`dist/renderer/assets/app-icon-C7NKj2u7.png` on October 14, 2026.
It identifies Grok Bot, which has a different mark from Grok Build.
Web, Desktop, and Website consume it through `LocalAgentLogo`.
