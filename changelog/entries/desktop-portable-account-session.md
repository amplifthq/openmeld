title: Read account details through a shared Desktop and Web API
kind: improved
areas: ["desktop", "account"]
audiences: ["developers"]
---

Desktop and Web share a credential-free account read that preserves profile
details, email verification, the Joined date, and the current Web session label.
The private Desktop pilot no longer needs a generated server-function identifier
for this read. Other pilot compatibility restrictions still apply.
