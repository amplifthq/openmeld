areas: [agents, computers, cli]

Center, Remote and Local Agents can use one persistent cloud Computer owned by
your account. Tasks can run commands concurrently, keep their own working
directories and stop their exact processes. File edits detect conflicting
changes. Downloaded personal copies remain available after a provider disconnect.

Local Agents can access the same files and commands with `openmeld computer cloud`.
Sharing a file with a Space remains an explicit action.
