Center Agent settings groups model choices by provider and supports searching
within a provider or across all providers. The curated list adds GPT-5.6 Terra,
GPT-5.6 Luna, Claude Opus 5, Claude Sonnet 5, Gemini 3.8 Flash, Gemini 3.5
Flash Lite, Gemini 3.1 Pro Preview, and DeepSeek V4.1 Flash alongside the
existing models.

Select a provider, choose a model, and save when ready. Existing selections,
the OpenMeld default, and work already in progress keep their current behavior.
