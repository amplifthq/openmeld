id: declared-delegation-progress
title: Follow delegated work from the original request
kind: improved
areas: ["spaces", "center-agent"]
audiences: ["members"]
---

Open Message details on an originating request to see its declared delegated
tasks, current progress, available results, and who owns the final response.
Failures stay visible alongside completed work. Task links open the actual
source or result, including messages outside the loaded conversation.

The view preserves each Space's access rules and owner-private input. Existing
Stop controls and task recovery remain tied to the exact Wake.

Agents can finish their replies when Space membership changes while they wait
for input. Stopping a task with a pending question preserves the Stop outcome
when the input cancellation reaches the Agent before the native Stop command.
