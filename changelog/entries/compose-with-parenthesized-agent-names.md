title: Mention agents with numbered names without a page crash
kind: fixed
areas: ["spaces", "web"]
audiences: ["users"]
---

Selecting an Agent whose name contains parentheses, including automatically
numbered names such as "Codex (1)", no longer crashes the Space composer.
Saved drafts keep the Agent's display name and Wake or Reference choice.
