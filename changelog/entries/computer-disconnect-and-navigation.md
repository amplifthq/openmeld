id: computer-disconnect-and-navigation
title: Disconnect Computers from Web and open Computer details in Desktop
kind: improved
areas: ["computers", "web", "desktop", "cli"]
audiences: ["users"]
---

The Computer connection menu in Web now provides a command to disconnect the
selected Computer. It stops the local Service and signs out the CLI while
keeping the Computer in your account.

In Desktop, selecting Computer from the account menu opens this Mac's Computer
details when connected, instead of returning to the Connect page.
