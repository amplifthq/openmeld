title: Center Agent can publish a Space image to a GitHub side branch
kind: improved
areas: ["center-agent", "spaces", "apps"]
audiences: ["members"]
---

Center Agent can place a PNG or JPEG from its Computer on a GitHub side branch
and return a link for an issue or pull request. The image stays in the selected
repository, and only people with access to that repository can view it. The
Agent does not need to download the entire repository to publish one image.
