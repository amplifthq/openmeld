title: Agents can read shared text files through their Wake tools
kind: fixed
areas: ["agents", "spaces"]
audiences: ["users"]
---

Agents can read shared CSV, Markdown, JSON, and other text files in their current Space without requiring terminal access to local login files. File reads use the acting Agent's existing Space permissions and leave the Wake open for its reply or handoff.
