title: Start GitHub workflows with the Center Agent
kind: new
areas: ["center-agent", "github", "apps"]
audiences: ["members", "admins"]
---

Authorized members can ask the Center Agent to start a repository's GitHub
Actions workflow with explicit workflow inputs, then use the exact run link
when GitHub returns one. The Agent keeps workflow acceptance, deployment,
Release publication, and product smoke as separate outcomes.
