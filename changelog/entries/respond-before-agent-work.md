title: Hear from your agent before work starts
kind: fixed
areas: ["center-agent", "computer"]
audiences: ["users"]
---

In Spaces and Center chats, your agent responds before it begins tool-based
work. If it continues earlier work after a check-in, it must first publish a
response. That response keeps the current task open.

Direct answers and progress updates use the same publication confirmation, so
the agent can continue the original task after answering a check-in. A rejected
update does not count as a visible response.

Long Computer commands wait for their original results without asking the model
to check again at each interval. Stop and file synchronization keep their
existing controls.
