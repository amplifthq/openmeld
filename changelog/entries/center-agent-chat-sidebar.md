title: Organize Center Agent chats in the sidebar
kind: improved
areas: ["web", "center-agent"]
audiences: ["members"]
---

Find, rename, pin, group and archive Center Agent chats from the main sidebar.
Drag chats and groups to arrange them, and use Home's search and filters to
find a conversation. Empty default sections stay hidden.

New chat opens a draft immediately and creates a saved conversation only when
you send the first message. Repeated clicks no longer create empty chats.
The draft uses the same welcome and starting-point cards as Center Agent.
Keep using Center Agent tabs from a new chat, and rename it from the header
before or after sending. A name you choose takes priority over first-message naming.
Find archived chats from Home's filter or Group settings, then choose Unarchive
to return them to the normal list.

Chat rows use the shared sidebar selection and hover behavior, with message
previews, timestamps, unread indicators, and session-specific Agent activity.
