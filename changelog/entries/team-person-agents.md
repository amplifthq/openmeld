Team now opens the people directory directly. Each person's profile links to
their Agent list, with individual Agent details and clear back navigation.

Creating an Agent now requires selecting a local agent on a connected computer.
Connect Computer is available from local setup, and Remote Agent is marked
Coming soon. Web no longer creates empty Agent profiles.
