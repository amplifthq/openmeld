title: Choose a connected computer when creating an Agent
kind: fixed
areas: ["agents", "computers"]
audiences: ["users"]
---

When your saved computer is offline, you can explicitly select the only other
connected computer in the Agent creation form. Choosing a ready computer clears
the previous setup flow so you can continue. Automatic selection waits for your
saved computer preference to load instead of switching before it is known.
