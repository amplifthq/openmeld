title: Keep local Agent capabilities in new tasks
kind: improved
areas: ["agents", "spaces"]
audiences: ["members"]
---

New Codex and Claude tasks keep the Agent's native tools and permissions,
including requests from teammates and other Agents. The Project chooses where
work starts. Optional file access limits remain available in the task menu and
Computer settings. Continuing a restricted task preserves its limits.
