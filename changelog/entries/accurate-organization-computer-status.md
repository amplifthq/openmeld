title: Show the current Computer status
kind: fixed
areas: ["computers", "directory"]

---

Organization Computer summaries now use each Computer's current OpenMeld
Service session instead of combining it with replaced sessions. Existing
Computers with unavailable status evidence are shown as unavailable, not as a
missing Computer that needs to be connected again.
