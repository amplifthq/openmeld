Antigravity Agent Profiles now offer the native Gemini, Claude, and GPT-OSS
model choices and configurable permissions. Model and Permissions panels no
longer open empty. Permission changes apply on the next run, including when
continuing a conversation.

Reconnecting the same account also keeps the new sign-in consistent while
OpenMeld Service starts, preventing setup from failing during the update.
