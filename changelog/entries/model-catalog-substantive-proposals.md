title: Model catalog reviews open only for substantive changes
kind: fixed
areas: ["developer-workflow", "model-catalog"]
audiences: ["contributors"]
---

Scheduled model scans open a draft pull request only when new model candidates,
model parameter differences, or changed retirement notices need review. Routine
upstream documentation and release changes remain in the scan artifacts without
creating another review. Closed proposals stay suppressed when only unrelated
source material changes.
