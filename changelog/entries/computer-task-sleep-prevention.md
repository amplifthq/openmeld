---
id: computer-task-sleep-prevention
title: Keep your computer awake during local Agent tasks
kind: new
areas: ["desktop", "settings"]
audiences: ["users"]
---

Turn on Prevent sleep while running tasks from your Local Computer page or
Desktop settings. Both entries control the same setting on that computer.
It is off by default.

On macOS and Windows, OpenMeld Service prevents automatic sleep while local
Agent tasks run. The screen can turn off, and quitting the desktop app does not
stop this protection. It releases when the last task ends or you turn it off.
Putting the computer to sleep yourself can still pause tasks.
