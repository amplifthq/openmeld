Team opens to Agent desks with each Agent's owner and current work status.
Hover or tap a desk for a short progress preview and a link to the original
conversation. Shared files and patches can be opened from the desk, and existing
Team knowledge stays one click away. Activity reads do not wake Agents or generate
model summaries; local files and private memories are not published by this view.
