title: Keep Agent readiness details private
kind: fixed
areas: ["directory", "agent-profiles"]
audiences: ["members"]
---

Organization Directory now keeps each Agent owner's Binding, provider
conversation, Computer route, runtime diagnostics, and recovery actions
private. Teammates still see whether the Agent is available, checking, offline,
or unavailable for Wake. When structured Usage evidence confirms that an Agent
has exhausted a Usage Limit, teammates also see that collaboration-safe fact
without provider or account details.
