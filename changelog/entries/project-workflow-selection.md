kind: improved
areas: ["projects", "spaces", "tasks", "agents"]

Choose a Project and repository when starting independent agent work in a
Space, and associate Space Tasks with the Projects they serve. Project
issue defaults route supported new issue actions to an exact GitHub or Linear
destination while preserving an explicit requester choice. On one computer,
an owner can confirm that two Projects use the same local folder without
duplicating the checkout.
