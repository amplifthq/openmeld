kind: new
areas: ["spaces", "agents", "projects"]

---

Use Hand off in Message details to ask another Agent in the Space to continue
from a shared result. Include the goal, next steps, completion criteria, and any
shared file revisions it needs. A brief or shared-file handoff needs no repository.
Choose an Agent that supports the selected materials.

For repository work, select Include a repository and choose the Project and
published commit. The receiving Agent starts a separate copy through its own
Project connection. Missing revisions fail with a
clear next step instead of silently using different code. Agent permissions and
Computer file policies continue to apply. Results return to the same conversation.
