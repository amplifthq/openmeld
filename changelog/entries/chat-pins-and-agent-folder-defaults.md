title: Keep pinned chats together and simplify Agent creation
kind: fixed
areas: ["web", "agents"]
audiences: ["users"]
---

Pinned conversations with people, local agents, and Center Agent now share one
group above Agents and People. Unpinning a chat returns it to its original group.

New Agents use Let OpenMeld choose instead of getting stuck on an unconfirmed
folder from saved settings. If a Project selected during creation has no
connected folder, a direct button lets OpenMeld choose a folder instead.
