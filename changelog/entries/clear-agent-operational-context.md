kind: improved
areas: ["agents", "web"]

Agent details now put current work, Wakeability, Usage reporting, and settings
timing together up front. Teammates can see a neutral work and queue summary,
including when reliable Usage is exhausted, without receiving Space, Computer,
Controller, or task details. Working Agents use a restrained active indicator,
Offline and Unavailable Agents stay quiet, and owner diagnostics remain under
Technical details.
