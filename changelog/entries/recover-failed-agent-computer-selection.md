title: Recover Agent setup without starting over
kind: fixed
areas: ["agents", "web"]
audiences: ["users"]
---

Failed Agent setup now opens the original setup details instead of an unrelated
new Agent form. Choose a connected computer while keeping the Agent's name,
model, and settings. Clearer guidance explains unavailable local agents and
how to continue or cancel setup. Retrying after a lost response reuses the
accepted attempt, and Agents already created keep their existing setup path.
