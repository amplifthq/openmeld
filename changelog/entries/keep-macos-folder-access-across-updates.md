id: keep-macos-folder-access-across-updates
title: Keep Mac folder access across updates
kind: fixed
areas: ["cli", "macos", "openmeld-service"]
audiences: ["members"]
---

After one possible macOS confirmation when this update introduces the stable
OpenMeld Service identity, later OpenMeld updates keep using that identity.
macOS should no longer ask for Desktop or Documents access only because
OpenMeld installed a newer version.
