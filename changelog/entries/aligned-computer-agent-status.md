title: Match Computer attention to local agent status
kind: fixed
areas: ["agents", "computers", "web"]
audiences: ["members"]
---

Computer summaries and navigation now judge only the local agents that are
turned on. A local agent that could not be checked uses the same amber
**Couldn't check** status everywhere, while local agents you turned off stay
quiet even when their hidden diagnostics report a problem.
