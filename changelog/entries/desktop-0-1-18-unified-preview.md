Desktop 0.1.18 brings the latest conversation, Inbox, and Skills improvements
to Mac and the Windows x64 preview, alongside OpenMeld Tools 0.3.238.

The Mac release is signed by OpenMeld and notarized by Apple. Existing installations can
update from Settings without signing in again. Windows x64 remains an unsigned
internal preview with a downloadable installer and no automatic updates.
