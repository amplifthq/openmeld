title: Keep Center Agent diagnostics tied to the right Slack thread
kind: fixed
areas: ["slack", "center-agent"]

When you ask Center Agent about earlier Slack work from a new thread, its
diagnostics now identify the exact source thread. Center Agent can explain an
earlier failure without presenting it as part of the current conversation.
