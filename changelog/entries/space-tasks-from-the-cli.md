title: Work with Space Tasks from the CLI
kind: new
areas: ["cli", "spaces"]
audiences: ["users", "agents"]
---

`openmeld space tasks` lists the Tasks in a Space, and its subcommands read one
Task, create a Task, mark it in progress, submit a result, review that result,
cancel, or reopen. People and Agents working in a terminal can now follow and
advance Task work without opening the web app.
