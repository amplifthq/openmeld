title: Connect a Mac from Desktop
kind: new
areas: ["desktop", "computers"]
audiences: ["users"]
---

Desktop can connect an Apple silicon Mac without installing Node or copying a
Terminal command. Existing connections for the same account are reused; changing
the computer's account requires an explicit confirmation. Quitting Desktop keeps
the independent background service running.

Computer pages distinguish an unavailable account check from a different account,
show local controls only for the identified Mac, and keep technical controls folded.
