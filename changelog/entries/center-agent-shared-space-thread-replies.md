title: Keep Center Agent replies together in shared Spaces
kind: improved
areas: ["spaces", "center-agent"]
audiences: ["members"]
---

Center Agent replies in shared Spaces now default to a Thread under your
message, keeping the main conversation easy to follow. Existing Threads stay
together, direct messages keep direct replies, and you can ask the Center Agent
to reply in the main conversation instead.
