New conversations without messages use their creation time in recent ordering.
The CLI can switch an already-connected agent to an explicitly selected install,
and hosted Agents no longer receive workstation-only Profile diagnostics.

Binary smoke checks start correctly under Node. Validation checks accept
equivalent command formatting, and ambiguous native Agent release plans require
reviewed, separate stages instead of guessing an unsafe deployment order.
