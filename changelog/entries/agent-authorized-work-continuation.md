id: agent-authorized-work-continuation
title: Fewer interruptions for work you already authorized
kind: improved
areas: ["center-agent", "agents"]
audiences: ["members"]
---

Center Agent can proceed with an explicitly requested removal or merge without
requiring another confirmation message. Identity, access, exact-action checks,
and protections against duplicate execution remain in place.

Center Agent and Local Agent instructions also clarify that supported task
continuations should resume the original work within its existing authorization.
This does not add external-event watching or change native Agent permissions.
