id: preserve-collaboration-review-context
title: Keep earlier teammate updates available during reply review
kind: fixed
areas: ["spaces", "local-agents"]
audiences: ["users"]
---

Local Agents retain a bounded view of earlier teammate updates when reviewing
an unpublished reply again. Review context identifies omitted messages and
truncated excerpts so Agents can read the original history when needed.

Collaboration guidance also makes clear that a requested personal answer is
still due when another teammate gives the same answer. The participant list
does not assign work or establish an execution order.
Requests to coordinate with another member are treated as assigned work, rather
than as a reason for the coordinator to stay silent.

Context-read instructions include the Agent's Profile explicitly, so reading
Space history or a thread does not depend on the terminal's selected profile.
Compact history also keeps attachment references and exact revisions, allowing
Agents to find files shared earlier when receiving a handoff.
Space File tools keep the Service's environment directory when launched by a
local Agent, so isolated environments use their own login state.
