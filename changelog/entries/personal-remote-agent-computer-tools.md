Personal Remote Agents can research the web, work with files and code on their
cloud Computer, use enabled Organization Skills and shared Apps, and return
files in their replies. Computer files persist within each conversation.

These capabilities reuse the Center Agent's tools while keeping organization
administration and private connections separate.
