id: approval-requests-appear-promptly
title: Agent approval requests appear right away
kind: fixed
areas: ["spaces", "local-agents"]
audiences: ["members"]
---

When a local agent asks for approval partway through a longer task, the request
now shows up in the open Space within about a second. Before, a request that
arrived after the task had been running for a while, which was common with
Claude Code, could take 10 seconds or more to appear.
