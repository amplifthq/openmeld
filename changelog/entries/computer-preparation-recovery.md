---
id: computer-preparation-recovery
title: Resume Computer preparation after an interruption
kind: fixed
areas: ["computer", "center-agent"]
audiences: ["users"]
---

Computer commands can resume interrupted file preparation with their original
request and files. Commands are marked as starting only after preparation is
ready, so an interruption during preparation does not leave an unstarted task
stuck waiting for a result. If a command may already have started, OpenMeld keeps
its existing record and does not repeat it automatically.
