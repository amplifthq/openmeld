title: Hand off work to another Agent
kind: new
areas: ["spaces", "agents", "projects"]
audiences: ["members"]
---

Use Hand off in Message details to ask another Agent in the Space to continue
from a shared result. Include the goal, next steps, completion criteria, and any
shared file revisions it needs. This handoff requires a Project and published
commit so the receiving Agent starts from the intended version.

The receiving Agent starts a separate copy through its own Project connection
and returns its result to the same conversation. Missing revisions fail with a
clear next step instead of silently using different code. Agent permissions and
Computer file policies continue to apply.
