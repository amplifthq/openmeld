id: computer-paused-observation-recovery
title: Preserve Computer recovery when automatic checks pause
kind: fixed
areas: ["computer", "center-agent"]
audiences: ["users", "operators"]
---

When automatic Computer checks pause, the Center Agent can explain what is
still unconfirmed without stopping the original command. A later authorized
request can collect the original result without repeating the command.
Explicit Stop remains available.
