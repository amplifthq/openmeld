title: Preview the latest unread message from the Mac menu bar
kind: improved
areas: ["desktop", "inbox"]
audiences: ["users"]
---

OpenMeld for Mac can show the latest unread message in its menu bar menu and
open that exact message or Thread reply without clearing other unread work. The
same compact menu also provides direct access to Inbox, the current app view,
Computer, and Settings.
