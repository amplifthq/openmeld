id: clearer-space-message-groups
title: Clearer Space message groups
kind: improved
areas: ["spaces", "direct-messages", "web"]
audiences: ["members"]
---

In the main Space conversation, consecutive messages from the same person sit
together, while different speakers have more room between them. Space
conversations use the full available width by default, with message bubbles
that fit their content. The first message in a group shows a simple 24-hour
time beside the name; later messages leave the time to Message details. Direct
messages keep their compact layout and show each message's hour-and-minute time
in its toolbar.

In the main conversation, actions float beside each message without moving the
conversation on hover. On narrow screens, the toolbar stays on the opposite
side of your message and keeps the remaining actions in More. In Threads, each
message shows its speaker and uses the panel width; actions appear in a reserved
row below the bubble.

Wake failures and stops from a Thread stay in that Thread instead of adding
unrelated notices to the main Space conversation.

Extra blank lines in Human messages appear as one blank line between paragraphs;
the original message text is preserved.
