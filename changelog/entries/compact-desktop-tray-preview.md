title: Shorter message previews in the Desktop menu
kind: improved
areas: ["desktop", "inbox"]
audiences: ["users"]
evidence: ["pr:1195"]
---

The Desktop menu uses a shorter single-line message preview, with the message
age beside Latest unread. Longer names, Chinese text, and emoji leave room for
a useful excerpt. The full message preview remains available on hover and to
screen readers, and selecting it still opens the exact message.
