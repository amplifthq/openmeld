title: Keep Agent avatars consistent across conversations
kind: fixed
areas: ["agents", "center-agent", "spaces"]

---

Saved Agent avatars now update across the sidebar, conversation picker, Space member list, profile card, reply header, and other open tabs. The avatar editor uses the saved appearance until you choose a preview. Failed saves return to the current saved avatar. Remote Agents use an Agent icon instead of the selected model vendor's logo, and missing preferences no longer invent a saved Bot avatar.
