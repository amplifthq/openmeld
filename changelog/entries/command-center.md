kind: new

Open the Command center from the sidebar search button or with Command-K
(Control-K on Windows and Linux). Return to recent Spaces with their unread
and Agent status, find People and Agents, open core pages, start a new Space
or message, and change the theme.

Recent Spaces follow your navigation in this browser. Message content search
is not included in this initial version.
