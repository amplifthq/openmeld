id: agent-profile-creation-requests
title: Coordinate Agent creation with teammates
kind: new
areas: ["agents", "inbox", "center-agent", "cli"]
audiences: ["members"]
---

Members can request an Agent owned by a teammate from Web, the CLI, a Local
Agent, or the Center Agent, then track, approve, decline, cancel, or retry that
request in one shared workflow. Each member can choose separate approval rules
for new Sessions and existing Sessions. Create Agent now opens directly into
the Agent form when additional Human Profile creation is unavailable.
