title: Check an Agent without leaving the conversation
kind: improved
areas: ["agent-profiles", "spaces", "direct-messages"]
audiences: ["members"]
---

Agent names and avatars in Spaces now open a compact profile with current
activity, setup details, and a Direct Message shortcut. Members see the same
profile content from the Members panel, while owners can update supported Agent
settings directly from the shared profile cards.
