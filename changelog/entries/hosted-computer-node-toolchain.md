title: Build and check JavaScript projects in the hosted Computer
kind: improved
areas: ["remote-agent", "computer"]

Hosted Agents can use Node.js 24 and pnpm in their cloud Computer to install,
build, and run JavaScript projects. They can open a running development server
in a private browser and check its rendered page without a connected local
workstation or a public preview URL.
