title: Sign in to Antigravity ACP and run independent tasks
kind: improved
areas: ["agents", "cli"]
audiences: ["users"]
---

Sign in to the selected official Antigravity ACP installation with
`openmeld agents login antigravity`. OpenMeld verifies that a new session can
use the saved sign-in. Account checks and agent runs do not open login windows.

Computer details show a sign-in command when it is needed. The legacy CLI shows
Installed when its account cannot be checked. Subscription usage remains
unavailable.

Start and continue independent Antigravity ACP tasks from the Web Session menu
or CLI. Tasks keep Agent permissions and can use a separate working copy.
Unsupported history forks and additional file access limits are not offered.

Select Gemini 4 Argon for Antigravity, Cursor, OpenCode through OpenRouter,
and hosted Agents. Availability depends on the selected provider and account.
Existing model selections and defaults stay the same.
