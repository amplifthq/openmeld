title: Create local Agents on the selected computer and Project
kind: fixed
areas: ["agent-profiles", "center-agent", "projects"]
audiences: ["members"]
---

Agent Profile creation now rechecks the selected local agent before creating
the Profile, so an unavailable computer no longer leaves behind an unusable
Agent. Web, CLI, and Center Agent creation also resolve the same Default Project
working folder instead of showing an OpenMeld-managed folder for Project-based
work.
