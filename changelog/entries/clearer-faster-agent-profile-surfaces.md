Agent previews now keep identity and avatar context visible, lead with a clear
Chat action, and separate the compact Space popover from the fuller Agent
details and editing experience. The Agents page also shows cached profile
identity while current runtime availability refreshes independently. Empty
activity sections stay out of the way, unavailable Agents explain what is
wrong and expose relevant recovery actions, and unbound Agents can connect a
local agent directly from the highlighted Model card. Owner details also show
the runtime computer and controller conversation ID when available.
