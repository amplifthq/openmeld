title: Keep Space Task handoffs and results recoverable
kind: fixed
areas: ["spaces", "agents", "web"]
audiences: ["members", "agents"]
---

Space Tasks now retain review handoffs, completion notices, and linked GitHub
issue updates until delivery succeeds. Task details show when a handoff or
execution stop needs attention. Canceling a Task follows its recorded Agent
Wakes, and a human Space owner can authorize further rework when an Agent task
reaches its review limit.
