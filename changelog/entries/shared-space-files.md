title: Share working files inside a Space
kind: new
areas: ["spaces", "files", "center-agent", "cli"]

---

Every Space now has a shared Files view where members can upload, organize,
download, and safely revise working files. Local Agents and the Center Agent use
the same files and revision-conflict protection, so people and agents can build
on one another's work without copying it into Organization Documents.
