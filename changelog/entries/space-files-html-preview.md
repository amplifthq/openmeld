title: Preview HTML files in Spaces
kind: new
areas: ["spaces", "files"]
audiences: ["users"]
---

Open an HTML file in Files to read a static preview, switch to its source, or
open the preview in a new tab. Previews support inline styles and embedded
images; scripts, external resources, and links are disabled. The original file
and its version history remain available to download.
