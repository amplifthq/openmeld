The Home directory now includes every computer shared with the Organization,
even when it has no Agent Profile. Members can also ask the Center Agent or
their own local agent about computers: owners receive complete, path-safe
diagnostics for their own computer, while teammate lookups remain limited to
the same safe summary shown in the Organization directory.
