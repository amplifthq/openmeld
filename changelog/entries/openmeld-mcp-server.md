`openmeld mcp` runs an MCP server that lets Claude Code, Codex, Cursor, Claude
Desktop, and other MCP clients read Spaces, send messages, and work with Tasks
as your signed-in OpenMeld profile. Add `--read-only` to expose only the tools
that read.
