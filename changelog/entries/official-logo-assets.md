OpenMeld's macOS app icon and browser icons have cleaner edges and adjusted
visual alignment. The macOS app, Web, Website, and Docs use assets from the same
generated brand set. Transparent and solid-background wordmarks are available
for light and dark backgrounds.

The documentation header uses the official wordmark. Select the logo to open
the main website, or select Docs to return to the documentation home page.
