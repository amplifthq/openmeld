OpenMeld icons have cleaner edges and adjusted visual alignment. Desktop,
browser icons, and public brand images share one generated asset set. Transparent
and solid-background wordmarks are available for light and dark backgrounds.
The documentation header uses the official wordmark. Select the logo to open
the main website, or select Docs to return to the documentation home page.
