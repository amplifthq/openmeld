id: working-folder-recovery
title: Choose how to continue when a conversation uses another folder
kind: fixed
areas: ["local-agents", "spaces", "inbox", "cli"]
audiences: ["users", "agents"]
---

When an OpenCode conversation uses a different working folder, OpenMeld asks
before starting the task. Continue the previous conversation, start a new one
with the same Agent, or stop. The previous conversation stays saved.

The request appears in the Space and Needs action. Answer in Web, Desktop, or
with `openmeld space respond`; terminal Agents receive the same explicit choices.
