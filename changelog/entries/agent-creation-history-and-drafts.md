title: Keep Agent creation settings and review creation history
kind: fixed
areas: [agents, web]

Changing advanced settings keeps the selected Agent and its form visible.
Create Agent remembers your latest choices even when you leave without creating
an Agent, and keeps them after creation. Connected computers no longer show an
unnecessary option to connect another computer.

Agent creation history presents creation results and retry actions in a table,
with readable explanations for incomplete setup instead of raw HTTP errors or
misleading request terminology. Incomplete creation opens its recovery history.

Settings cards now morph into centered dialogs while keeping the same layout and
appearance. Working folder uses the shared Fluid selectors and keeps folder
selection inside its editor. Reconnecting the same computer restores its local
Agent choices instead of leaving creation on the old connection.

One primary button guides you through any remaining settings, then changes to
Create Agent when everything is ready.

Local and Remote Agent names are editable titles with a subtle text transition.
Each Agent type keeps its own name draft after a refresh until you create the Agent.

People, Agents, and Plugins share the Team people sidebar, so you can find a
teammate from any tab. Plugins uses the same content margins as the Team directory.
The catalog and Plugin settings open without waiting for connection-status retries.
