title: Keep Agent creation settings and review creation history
kind: fixed
areas: [agents, web]
audiences: [members]
---

Changing advanced settings keeps the selected Agent and its form visible.
Create Agent remembers your latest choices even when you leave without creating
an Agent, and keeps them after creation. Connected computers no longer show an
unnecessary option to connect another computer.

Agent creation history presents creation results and retry actions in a table,
with readable explanations for incomplete setup instead of raw HTTP errors or
misleading request terminology. Incomplete creation opens its recovery history.
