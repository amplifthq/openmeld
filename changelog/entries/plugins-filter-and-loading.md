title: Filter connected Plugins and keep loading out of your way
kind: improved
areas: ["web", "plugins", "spaces"]
audiences: ["users"]
---

Filter Plugins to the connected accounts in your selected workspace or Personal
scope. Search and category filters work together, including accounts that need
reconnection.

Plugin requests start earlier and load independently, with skeleton rows while
results arrive. Threads reuse message skeletons, and the opening screen shows
only the OpenMeld logo.

Plugin details show known names, logos, and navigation immediately, with
skeletons for settings until live setup information is available.

Plugin details put Connect or Connected beside Website. Select Connected to
review the account and confirm disconnection. Agent access has a Save access
button beside its heading, and credential setup stays available below.
Each detail page also includes a short description of what the Plugin can do.
