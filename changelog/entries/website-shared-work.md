Explore OpenMeld from the homepage without creating an account. The demo uses
real product components with fictional data. Open a shared Space, try the
message editor, open the member panel, pin a conversation, filter the Inbox,
mark updates as read, and explore all six Team tabs. Open People and Agent
profiles, browse Plugins, files and Skills, or edit and pause a sample Routine.
Changes stay in the page and reset on reload. The homepage also explains local
agents, shared team context, Slack access, and cloud computers.

Use the member picker to mention people or wake sample Agents. Try sending a
message and see the sending state, Working indicators, and a short demo reply.
The checkout example shows a teammate’s Agent checking a fix with another Agent.
Send the prefilled request in one click. Working appears in the Agent’s reply.
Mention-only tokens do not wake Agents. File uploads are disabled in the demo.

Choose a local or remote Agent in the focused creation preview. Select a cloud
model and see its provider avatar. Explore Slack, Lark, and Feishu conversation
examples, including expandable threads.
Explore a dedicated Center Agent preview with an interactive avatar and model
selection. Compare organization and personal AI usage, and expand cloud cost
and local-agent token details in the product's charts and tables.
Browse the available app integrations and their supported actions. The homepage
shows shared app logos and explains that more integrations are on the way.
The homepage also includes an open-source link and Desktop and Web badges.
Layered Files, Skills, and Routine views show the product with sample work;
open their details without navigating a small embedded page. The cloud-computer
overview explains the personal Computer shared by local and cloud agents.
Motion respects reduced-motion preferences.

Open the Web app or choose a macOS or Windows download from the homepage.
