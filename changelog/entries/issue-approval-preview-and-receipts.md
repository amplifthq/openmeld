title: Review issue content before approving
kind: fixed
areas: ["plugins", "center-agent"]

---

Linear and GitHub issue approvals can show the original title and description
alongside the account and destination. Linear destination names are checked
using the selected account; unavailable names remain clearly labeled with their
IDs. Recoverable issue approvals continue with a short acknowledgement instead
of exposing internal execution instructions in the conversation.
