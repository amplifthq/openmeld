title: See organization and personal Agent usage in Settings
kind: new
areas: ["settings", "agents"]
audiences: ["members"]
---

Settings now has a Usage page with Organization and My agents views. See recorded
model costs over time, compare models, and check your own Remote Agents in the
same place. Organization-wide Local Agent tokens stay separate from model costs.
Period selection, refresh, and breakdowns are tucked into Details. Model costs
are marked Free, and the existing 50-Routine limit stays unchanged.
