id: larger-portable-skill-packages
title: Install Skills with larger supporting files
kind: improved
areas: ["skills", "team"]
audiences: ["organization-admins"]
---

Team admins can install portable Skills with up to 256 supporting files and 8 MB of instructions and resources. A published version keeps its resources separately so Agents can fetch the exact file they need. Packages beyond these limits still show a clear blocker before installation.
