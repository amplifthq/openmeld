id: preserve-existing-codex-thread-model
title: Keep existing Codex thread model settings
kind: fixed
areas: ["agent-profiles", "cli", "service"]
audiences: ["members"]
---

OpenMeld no longer replaces an existing Codex thread's model or reasoning
settings with the catalog default when its Agent Profile Binding has no explicit
selection. You can also set an explicit model while adding the current agent to
a Space with `openmeld space add-me`.
