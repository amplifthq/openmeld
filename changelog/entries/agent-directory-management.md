kind: improved
areas: ["agents", "web"]

Filter Agents by Local or Remote, search within each person's list by name,
model, or vendor, and remove individual filter chips or reset the view.
Model and Controller icons make choices easier to recognize.

Select your Agents and delete several at once, with an exact confirmation and
individual failure feedback. Creation history is now beside your name and
includes search, filters, and a Needs attention shortcut.
