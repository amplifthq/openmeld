title: Find and compare Center Agent model choices
kind: improved
areas: ["center-agent", "web"]
audiences: ["admins", "owners"]
---

Center Agent settings now lets owners and admins search the curated primary
model list by name or model ID while keeping the current model visible.
Before saving, the settings explain when the change takes effect and how
switching models can affect prompt caching and input costs. Work already in
progress keeps its current model.
