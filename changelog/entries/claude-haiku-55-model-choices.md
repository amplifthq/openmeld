Choose Claude Haiku 5.5 for Claude Code, Cursor, OpenCode Zen and Go, the Center
Agent, or a personal Remote Agent. Claude Code requires version 2.1.293 or later.
Your provider account must have access to the selected model.

Claude Code, OpenCode, and hosted Agents offer five reasoning levels. Cursor
uses its provider-defined model configuration. Existing default models and
saved selections stay the same.
