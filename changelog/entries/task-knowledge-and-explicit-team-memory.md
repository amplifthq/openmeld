---
id: task-knowledge-and-explicit-team-memory
title: Keep team knowledge available without saving every shared conversation
kind: improved
areas: ["memory", "documents", "skills", "agents"]
audiences: ["members", "admins"]
---

Shared conversations no longer automatically add team or personal memory.
Explicit team saves and private-chat memory continue to work. Personal recall
can no longer use the entire space reserved for relevant team memory.

Agents can discover approved documents and task-selected Skills, then read the
instructions they need. Task reads preserve document versions and exact Skill
releases without exposing drafts or granting additional action permissions.
Remote Agents can also read approved knowledge when another Agent delegates
the task. Local task tools, including direct messages, remain discoverable
through strict controller checks.
