The homepage compares OpenMeld with six agent workspaces across collaboration,
knowledge, memory, Skills, file versions, task review, execution, integrations,
and licensing. The compact table keeps limited support and unverified features
visible, with horizontal scrolling on smaller screens.

The leading Cloud Computer row distinguishes the free personal Computer from
competitor starter credits and free cloud tiers. The footer adds creator credit
and a Contact link.
