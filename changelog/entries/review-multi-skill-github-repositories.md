---
id: review-multi-skill-github-repositories
title: Review every Skill in a GitHub repository before installing
kind: improved
areas: ["center-agent", "organization-skills"]
audiences: ["organization-admins"]
---

Organization admins can ask Center Agent to inspect a GitHub repository with
multiple Skills. The review lists each Skill at one commit, shows file size
limits that would block installation, and warns when scripts will be stored but
cannot run. A reported installation repeats those warnings in its result.
