---
id: agent-creation-guided-recovery
title: Create Agents without repeating permission confirmations
kind: fixed
areas: ["agents", "web"]
audiences: ["users"]
---

Creating another Agent with saved permissions no longer asks you to confirm
the same permission mode again. New permission choices still show their
confirmation, with a direct button that opens the right setting.

Working-folder issues offer a one-click option to use an OpenMeld-managed
folder. A selected local agent can continue while discovery refreshes, and
managed-folder creation no longer waits for the Project list.
