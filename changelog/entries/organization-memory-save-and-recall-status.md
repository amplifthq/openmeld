title: Clearer organization memory status
kind: fixed
areas: ["center-agent", "memory"]
audiences: ["users", "admins"]
---

The Center Agent distinguishes a memory save that is still processing from one
that has finished processing. Organization memory settings show a recall
availability check, and the agent receives an explicit status when memory cannot
be read. Overlapping reply callbacks no longer collect the same private turn
twice.
