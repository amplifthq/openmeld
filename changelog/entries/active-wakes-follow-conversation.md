---
id: active-wakes-follow-conversation
title: Keep Agent progress with the latest conversation
kind: improved
areas: ["spaces", "agents"]
audiences: ["users"]
---

Active Agent replies stay after the latest message in their Space or Thread,
so new messages no longer bury ongoing work. Each Wake keeps its own status,
Stop control, and link to the original request. Finished replies appear in
publication order.

Text messages sent from the main conversation appear immediately while current
Agent availability is checked. A failed check leaves the message unsent and shows why.

Approval cards focus on the pending decision, with an optional permission-mode
update instead of a separate settings button.
