Members can request invitations by email or share a link for people to request
access. Organization owners and admins review each request from Inbox or email.
Approved invitations can include a specific Space, and recipients join only
after accepting the invitation.

Shared links, including existing links, no longer grant membership on their own.
Owners and admins can still send email invitations directly. Web and CLI use the
same approval rules, and a failed invitation delivery stays available to retry.

Review invitations inside Settings, with matching email and Inbox links and an
amber reminder for requests that need attention. Organization settings now have
separate General, Members, Invitations, and Security pages. Personal Agent creation
permissions live under Privacy & Safety and explain how existing conversations
can be used.

Creating Agents from Add People or Agents stays in one dialog. Return to the
picker with each new Agent selected, then add everyone to the Space together.
