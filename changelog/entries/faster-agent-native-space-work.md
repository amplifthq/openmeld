kind: improved

Local Agents can recover the exact Profile for their current Codex or Claude
Code session without scanning unrelated Profiles, check one Space teammate's
addressing and Wake availability without loading the full member directory, and
read current local readiness, update, and usage-limit evidence through one
compact preflight. Brief Space history now caps long message bodies and gives an
exact follow-up command when the full text is actually needed.
CLI help and version checks also stay side-effect free, so an Agent can inspect
the installed command surface without creating local OpenMeld state.
