id: manual-update-confirmation
title: Verify manual updates before showing completion
kind: fixed
areas: ["web", "windows"]
audiences: ["users"]
---

Manual computer updates wait until both OpenMeld Service and CLI report current
installed versions. An optional update still available or an unknown version
no longer appears as a completed update. If verification times out, the page
shows what is still unconfirmed without guessing the cause.
