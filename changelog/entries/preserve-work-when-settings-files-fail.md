---
id: preserve-work-when-settings-files-fail
title: Keep unfinished work when Settings cannot load
kind: fixed
areas: ["web", "spaces", "settings"]
audiences: ["users"]
---

Unfinished Space creation prevents automatic page updates from discarding its
name or visibility choice. If Settings files cannot load while work is unsaved
or a message is sending, the error stays inside Settings so you can close it
and return to your work.
