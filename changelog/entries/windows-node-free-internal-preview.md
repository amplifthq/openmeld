The internal Windows x64 preview installs OpenMeld Tools without asking coworkers
to install Node.js, npm, Bun, or .NET first. The Web setup command and Windows
Desktop use the same managed Computer connection. This unsigned trial is for
known coworkers; Windows may show a warning, and the Desktop trial does not
update itself automatically.
