areas: ["agents", "center-agent"]

Choose a supported reasoning effort when creating or editing a Remote Agent. Organization admins can also set the Center Agent's reasoning effort. The Center Agent's OpenMeld default is Claude Opus 5.5 at Medium, and new Remote Agents default to GPT-6 Sol at Medium. The same model and effort choices are available through the CLI and Center Agent tools, and the selected effort applies to new work.
