title: Choose reasoning effort for hosted agents
kind: improved
areas: ["agents", "center-agent"]
audiences: ["members", "admins"]
---

Choose a supported reasoning effort when creating or editing a Remote Agent. Organization admins can also set the Center Agent's reasoning effort. The same model and effort choices are available through the CLI and Center Agent tools, and the selected effort applies to new work.
