id: center-agent-private-memory-scope
title: Keep private Center Agent memory personal
kind: fixed
areas: ["center-agent", "memory", "channels"]
audiences: ["members", "admins"]
---

Eligible details learned in private Center Agent conversations now stay with
the verified member across OpenMeld, Slack, Lark, and Feishu. Shared
Organization conversations can still build Organization memory, while
externally shared channels do not contribute to it automatically. Private and
externally shared conversations also cannot write through the explicit
Organization memory save path.
