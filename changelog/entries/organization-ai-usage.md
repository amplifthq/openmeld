Center Agent settings now shows today's shared AI model costs instead of a
Wake count. AI usage remains free with no daily limit by default; Routines
keeps its existing limit.

Ask Center Agent for usage by model, Space, or Agent. Supported Local Agents
report their native token counts separately, without spending the shared
allowance. Missing costs stay clearly marked. Tracking begins with new
executions; older activity is not backfilled.
