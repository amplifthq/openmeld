The Agent directory starts with compact group cards for local controllers and remote model
providers, with avatar previews and a remaining count. Open a group to see its Agents
in place, or choose Expand all to return to the flat list. Existing search, filters, sorting, and model grouping remain
available. Avatar transitions respect reduced-motion preferences.
