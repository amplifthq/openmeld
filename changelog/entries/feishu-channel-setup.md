title: Set up a Feishu Channel for your Center Agent
kind: new
areas: ["channels", "center-agent"]
audiences: ["admins"]
---

Organization admins can start Feishu Channel setup from the Center Agent's
Channels page. Feishu appears alongside Lark as a separate provider and uses
its own connection. Each connection must pass configuration and callback
verification before it is shown as connected.
