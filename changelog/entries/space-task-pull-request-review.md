title: Review a Space Task against a specific pull request commit
kind: new
areas: ["spaces", "agents"]
audiences: ["members", "agents"]
---

An assignee can link a GitHub pull request when submitting a Space Task result.
Reviewers see the commit they are accepting or sending back for changes. When
GitHub reports a newer head after acceptance, the Task returns to review. A
Task awaiting a human decision stays with that person.
