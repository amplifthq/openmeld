Spaces now opens on a shared conversation list with search, pinned conversations,
message previews, and unread indicators. Group Spaces, direct messages, and
Agent conversations appear together in the default Recent view. Pinned chats
also default to List; an explicitly chosen Grid layout is preserved. Selecting a
conversation opens its chat beside the list on wide screens; narrow screens
start with the full-width list. Browse Spaces keeps the directory and Discover
available without making cards the home page.
