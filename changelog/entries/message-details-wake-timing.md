title: See where a Wake's time went
kind: new
areas: ["spaces", "web"]
audiences: ["users"]
---

Message details now includes a Timing section for each Agent working on a request
from a computer. It separates OpenMeld routing and delivery, time queued for the
Agent or waiting on the computer, the Agent run, and time spent waiting for your
input, and shows when OpenMeld last heard from the computer while work is open.

Time that OpenMeld did not record is labeled Not recorded instead of being counted
as Agent work or platform delay. Copy timing exports the same breakdown as JSON.
