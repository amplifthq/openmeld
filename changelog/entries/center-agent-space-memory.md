Center Agent can retain messages sent to it in a shared Space for use in that
same Space, while keeping them separate from personal and Organization-wide
memory. Recall checks current access and the original message versions.

Explicit Organization saves from OpenMeld conversations preserve the complete source message's
original author, version and time. Context limits omit whole facts instead of
cutting off conditions or exceptions. The Organization memory setting also
controls Space capture.
