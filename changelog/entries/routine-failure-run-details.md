title: Find the exact Run behind a failed Routine
kind: improved
areas: ["center-agent", "routines"]
audiences: ["members"]
---

Failed Routine messages now include the Run ID. When a Center Agent Routine fails in an OpenMeld Space, the message also links to that Run's history and details. If the Agent produces no reply, the message explains that the Run ended without a result and that a member can request the work again.
