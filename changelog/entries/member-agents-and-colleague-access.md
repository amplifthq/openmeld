Each local Agent on your computers now appears once per harness, such as
Claude Code or Codex, with its Profiles and chats in one place. The Agents
page shows whether each Agent is available, what it is working on, and its
recent conversations.

Teammates can ask to use your Agent from a chat. You decide in the chat or
Inbox whether to allow it once, always allow it, or decline, and nothing runs
until you choose. You can review, upgrade, or remove access later from the
Space members panel; removing access stops new work right away. The CLI adds
`openmeld agent` and `openmeld session` commands for the same Agents and
chats.
