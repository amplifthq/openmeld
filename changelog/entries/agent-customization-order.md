Agent customization now starts with the owner's avatar and model, followed by permissions, session, working folder, and collaboration. New models appear at the top of the reviewed model list without changing your default or saved model selection.

New Agent pages use the current step as the main heading and leave more room for setup by removing duplicate headings and footer dividers. While checking local agents, the page no longer prematurely asks you to connect your computer.
