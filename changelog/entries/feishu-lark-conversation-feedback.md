title: Clearer conversation feedback in Feishu and Lark
kind: improved
areas: ["channels", "center-agent"]
audiences: ["members"]
---

Feishu and Lark show a receipt before loading conversation history and attachments.
Response cards distinguish a completed reply from a failed or stopped request,
and identify when a long response continues in another card.

The Center Agent's instructions also clarify that a self-contained answer should
stay in the current conversation, respecting requests to avoid tools or delegation.

The Center Agent can read rich-text messages with titles, links, code blocks and
embedded images, and retain rich-text content when reading conversation history.

Files attached to the current Feishu or Lark request can be read up to 5 MB.
Text files receive a preview; when Computer is available, original files are
saved there for further processing.
