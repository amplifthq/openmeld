title: Keep new Agent work in the right language
kind: fixed
areas: ["center-agent"]
audiences: ["members"]
---

When an Agent starts a new Space, handoff, or delegation, it now decides the
first message's language from the user's request, conversation, audience, and
requested artifact before writing. The Organization working language remains
advisory, and each receiving Agent keeps the final language judgment.
