title: Update your Center Agent while it works
kind: improved
areas: ["center-agent", "web"]
audiences: ["members"]
---

Send a text update in your Center Agent chat while it is working to add a
correction or missing detail to that response. Updates stay attached to the
original response, including during network retries. If an update cannot be
confirmed before the response ends, the chat tells you so you can review the
result and send it again.
