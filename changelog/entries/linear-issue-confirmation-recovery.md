id: linear-issue-confirmation-recovery
title: Create Linear issues with clear approval status
kind: fixed
areas: ["plugins", "center-agent"]
audiences: ["members"]
---

Explicit requests to create a Linear issue in a known team and project no longer
require a second destination approval. When confirmation is needed, the Agent
keeps the original operation for continuation and can check whether approval is
pending, decided, or unable to resume without submitting another issue.
