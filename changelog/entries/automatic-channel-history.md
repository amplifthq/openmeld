title: Use Feishu context without another setting
kind: improved
areas: ["channels", "center-agent"]
audiences: ["users", "admins"]
---

The Center Agent can use permitted Feishu context when a request needs it, without a separate group-history switch. New bot setup goes directly to Feishu consent. Admins can update the permissions of an existing bot from Manage Feishu. Requests to earlier discussion keep their bounded, requester-only scope and explain any missing context.
