title: Show ready Plugins in the catalog
kind: fixed
areas: ["plugins", "web"]
audiences: ["users", "admins"]
---

The Plugins browser now shows OpenMeld's selected Plugins with a configured
connection path instead of the full upstream provider directory. Existing
connections stay accessible for management. Missing logos display a Plugin icon
instead of an empty image, and catalog loading failures show a retry action.
The website no longer presents the catalog entry count as a live availability
count.
