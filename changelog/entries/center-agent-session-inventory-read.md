title: Let the Center Agent look up Local Agent Sessions itself
kind: fixed
areas: ["agent-activity", "center-agent", "agent-profiles"]
audiences: ["members"]
---

The Center Agent can now list the current Organization Session Inventory and
complete Fork or Resume from a native Session title or Session ID. It copies
Project, Computer, and local agent from that same current Session row instead
of asking the member to fill those fields or move to a private chat.
