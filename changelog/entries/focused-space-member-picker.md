title: Add Space members in a focused dialog
kind: improved
areas: ["spaces", "web"]
audiences: ["members"]
---

Members can open the same Add People or Agents dialog from the Members header,
the one-member empty state, or Space setup guidance. The focused picker groups
each person's Agents beneath them, supports selecting either a person or an
Agent, and keeps Agents already in the Space checked and easy to recognize.
Recent OpenMeld activity replaces generic availability copy, while the Members
panel uses the same expandable person-and-Agent structure without nested cards.
The Organization's remote Center Agent appears first, clearly labeled Remote.
