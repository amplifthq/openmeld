title: Clearer failure when a hosted agent runs out of response space
kind: fixed
areas: ["agents", "center-agent"]
audiences: ["members", "admins"]
---

When a hosted agent uses up its model's response limit before writing a reply, OpenMeld now explains what happened and how to continue. Completed actions remain in place so members can review them before sending a shorter follow-up.
