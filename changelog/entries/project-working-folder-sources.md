title: Choose a working folder from a shared project
kind: improved
areas: ["projects", "agent-profiles"]

Create or edit an Agent with one consistent working folder control: choose a
folder on your computer, use a shared project, or let OpenMeld manage the folder.
Create and edit projects within that flow without visiting a separate page.

Previously connected project folders load without waiting for repository
discovery. Existing repositories can be reused, and retrying project creation
does not create duplicates. Changing a project's default folder clearly explains
which Agents will use it.
