title: Center Agent joins Chats
kind: improved
areas: ["web", "center-agent"]
audiences: ["users"]
---

Chats brings conversations with people, local agents, and Center Agent together,
with participant filters and existing chat groups. Open Center Agent from Team
to continue its full conversation experience, including Files, Tasks, and the
other familiar tabs. New chat keeps the same Center Agent draft flow, and old
conversation links continue to work.
Home continues to open the existing default Center Agent conversation directly,
with the same welcome cards, composer, and tabs as Chats.
Opening Chats takes you straight to the first conversation in your sidebar.
Start a chat or filter conversations from the controls beside Chats.
Agents and People keep the list simple, with draggable group ordering. Center
Agent uses its profile avatar and a small header badge. Contextual search is
available inside filters, and the selected destination keeps its controls visible.
Local Agent chats use a matching computer badge. Center Agent chats now include
the shared Members panel for viewing participant profiles while keeping the
conversation private.
Loading placeholders now follow the chat list layout, including avatars,
titles, timestamps, and message previews.
