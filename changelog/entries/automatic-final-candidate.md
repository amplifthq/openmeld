---
id: automatic-final-candidate
title: Ready pull requests start final checks automatically
kind: improved
areas: ["developer-workflow"]
audiences: ["contributors"]
---

Final Candidate checks start automatically when a ready pull request is opened,
updated, or reopened, or when a draft is marked ready for review. Contributors
no longer need to remember a label or command to start required checks.
Draft pull requests stay idle while work or a combined batch is being prepared.
