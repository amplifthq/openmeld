The repository now has a concise product overview, categorized documentation,
and a contribution guide with a local docs preview that needs no team secrets.

Community policies explain how to get help, report vulnerabilities privately,
and handle third-party licenses. Issue and pull request templates make reports
and proposed changes easier to review.
