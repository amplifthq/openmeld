---
id: safe-installation-switching
title: Change local agent installations without interrupting work
kind: improved
areas: ["computers", "local-agents", "web"]
audiences: ["members"]
---

Computer details now show each local agent's selected installation in one
compact control above Usage. OpenMeld asks for confirmation before changing it
and prevents the change while that agent has work in progress, so queued or
running work cannot start with an unexpected installation.
