kind: fixed
areas: ["remote-agent", "center-agent"]

Hosted Claude Agents can reuse identical instructions, tool definitions, and
conversation context through prompt caching, reducing the cost of repeated
input while keeping the selected model and full context. Savings depend on
provider cache hits.
