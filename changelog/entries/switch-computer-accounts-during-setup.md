title: Switch computer accounts during setup
kind: fixed
areas: ["authentication", "cli", "setup"]
audiences: ["members"]
---

Setup commands copied from OpenMeld Web now accept keyboard choices when they
ask to switch a computer from one account to another. If no interactive
Terminal is available, setup stops immediately and explains how to retry
instead of leaving an unusable prompt onscreen.
