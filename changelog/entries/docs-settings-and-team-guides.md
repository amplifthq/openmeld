New guides explain App settings, Team tabs, and Center Agent configuration.
Task guidance now includes private conversations and the create-and-start flow.
Organization management, AI usage, Skills, and Files guides include more steps,
and Channels, Memory, and Security instructions use their current settings paths.

Guides now follow product areas, with separate Center Agent, Remote Agents,
Local Agents, Spaces, Team, and Settings categories. Existing article URLs stay
available. Agent-specific overviews link to shared Skills, Files, and Routines
instructions without duplicating their full workflows.

A dedicated Security & Privacy section explains Organization controls, local
permission modes, private information, task context and delegation, and data
storage. It separates instructions from enforced permissions and describes
the scope of diagnostic minimization and deletion controls.

The guides also clarify file-access exceptions, reported local-tool metadata,
hosted history retention, one-step delegation identity checks, and incomplete
pause cancellation. Space and message-to-Task steps match the current controls.

An Agent Harness section explains shared Space context, multi-agent handoffs,
context management, prompt caching, execution limits, and recovery. It identifies
which safeguards apply to hosted work and avoids guarantees about loop prevention
or token savings across all Agents.
