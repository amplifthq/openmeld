id: paused-agent-work-recovery-intent
title: Keep paused Agent recovery tied to the work you chose
kind: fixed
areas: ["agents", "web"]
audiences: ["users"]
---

Recovery actions from an older page can no longer start or skip a later
interrupted task. If the paused work changes while a confirmation is open,
OpenMeld closes it so you can review the current work. Continuing an occupied
conversation on a new branch also keeps the task identity throughout the request.
When another app keeps a conversation occupied, background status updates no
longer prevent OpenMeld from offering recovery options after the waiting period.
