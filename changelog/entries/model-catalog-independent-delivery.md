title: Get model catalog updates without updating the CLI
kind: improved
areas: ["cli", "agents"]
audiences: ["users"]
---

Online model catalog updates no longer require a new OpenMeld CLI release.
The CLI keeps a built-in catalog for offline use, and your saved model selections
stay unchanged. New local execution capabilities still require a compatible
agent controller and OpenMeld version.
