kind: new
areas: ["agents", "computers", "web"]

OpenMeld can now detect and run the Antigravity CLI, continue its native
conversations, stop active work, and show its signed-in weekly Usage Limits.
Antigravity appears across setup, Computer details, Agent creation, and install
guides. Agent creation now keeps every supported Local Agent visible and gives
a direct fix when the selected one is not installed, disabled, or signed out.
