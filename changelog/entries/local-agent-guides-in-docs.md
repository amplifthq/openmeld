Local Agent setup guides now sit alongside computer connection and task guides
in Docs. Each supported tool has its own navigation entry and logo. Existing
website guide links redirect to the corresponding documentation page.

A new Connect with an agent guide provides a copyable setup prompt and a link
to generate private setup access in the App. It explains how to confirm the
computer connection and handle expired authorization.
