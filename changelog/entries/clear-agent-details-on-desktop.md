title: Clearer Agent details in Desktop
kind: fixed
areas: ["agents", "desktop", "projects", "spaces"]
audiences: ["members"]
---

Opening an Agent's current Space from Desktop no longer leads to a page error. Agent details wait for the saved model before naming it and show the selected Project instead of assuming an OpenMeld-managed folder. Project choices for new work remain available while the Agent is working; changing a folder on the computer waits until the current task finishes. Password-protected Spaces open in Web for password entry.
