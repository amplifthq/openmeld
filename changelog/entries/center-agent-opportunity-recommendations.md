id: center-agent-opportunity-recommendations
title: Review useful opportunities with the Center Agent
kind: new
areas: ["center-agent", "inbox"]
audiences: ["members"]
---

The Center Agent can save one evidence-backed opportunity for the member it is
speaking with, keep it available in Inbox, and record whether the member wants
to pursue it, leave it for later, or dismiss it. Accepting a recommendation
does not run the suggested action or grant new permission.
