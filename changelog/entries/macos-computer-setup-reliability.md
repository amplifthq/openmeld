title: More reliable Mac setup downloads
kind: fixed
areas: ["computer-setup", "desktop", "cli"]
audiences: ["members"]
---

Mac setup now stops when its download fails or is incomplete, retries stalled downloads, keeps production downloads on HTTPS, and checks that production CLI binaries carry OpenMeld's expected Apple signing identity before installation. Connection instructions also describe Service startup failures without assuming macOS blocked the background item.
