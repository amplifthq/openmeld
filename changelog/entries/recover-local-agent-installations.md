title: Recover local agents after installation changes
kind: fixed
areas: ["agents", "setup"]

OpenMeld follows verified Codex runtime moves within the same desktop app after
an update. Local agent details separate installation selection from launch
readiness and let you choose a replacement even when only one working install
remains. Missing installations and file permission failures now have clear
repair guidance without exposing local file paths.
