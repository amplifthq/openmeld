title: Create personal Remote Agents
kind: new
areas: ["agents", "spaces", "chats"]
audiences: ["members"]
---

Create a Remote Agent with its own model without connecting a computer. Chat
with it directly or add it to a Space, where it can ask another Agent for help,
including another Agent you own. Each Agent keeps separate conversations for
each Space and does not inherit the Center Agent's administration or memory.
