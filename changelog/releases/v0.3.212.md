# v0.3.212

Released September 16, 2026

## New

### Choose more OpenCode and Cursor models

OpenCode Agent Profiles can now select DeepSeek V4.1 Flash and Hy4 Preview
through OpenCode Go, or Ling 3.0 Flash Fin Free through OpenCode's free route.
Cursor Agent Profiles can also select Claude Opus 5, Grok 4.6, and Muse Spark
1.3 when the signed-in Cursor account offers those exact choices.

### Download and update OpenMeld Desktop

Download Desktop from the Web account menu. Installed Desktop can check for a
new version, show download progress, and restart to update when you choose.
Choosing Later keeps the current version installed. Restart waits until drafts
can be saved and pending messages and uploads are finished. Updates in Settings
keeps the installed version visible while showing the available version and its
current download or restart state separately.

### See unread Inbox items in the Mac menu bar

The OpenMeld menu bar icon shows your current workspace's unread Inbox count,
including ordinary messages, even when the Desktop window is hidden. The number
is independent of notification permissions and disappears when there are no
unread items, the count is unavailable, or you sign out.

## Improved

### Clearer computer connection controls in Desktop

Desktop shows when this Mac is connected and lets you disconnect it with
confirmation, keeping your Desktop sign-in and saved computer record. Computer
details also offer Forget this computer, and Back returns to the profile you
started from.

Connection setup shows its actual progress and preserves useful failure details
for retry and diagnosis. Disconnect requires updated OpenMeld Tools.

### Clearer Space member additions

The Space member picker clearly separates adding existing teammates from creating
an Agent or inviting someone by email. Reopening refreshes an outdated list while
keeping cached results available. If the update fails, the picker preserves your
selection and offers a retry.

### Open messages from notifications with less waiting

Browser notifications open conversations without reloading the app. Desktop
brings its window forward promptly and reuses the checked notification target.
Linked Threads can show messages while the rest of the Space is still loading.

## Fixed

### Keep Desktop work safe through native interruptions

OpenMeld Desktop now keeps unsent drafts through temporary sign-in rechecks,
opens safe web links in your system browser, returns to normal close-to-hide
behavior after a blocked quit, and refreshes Space access when the live
connection reports that permissions changed.

### Recover interrupted OpenMeld Tools downloads

OpenMeld Tools updates now keep progressing on slow connections and make
bounded retries after temporary download interruptions instead of ending at a
fixed one-minute limit. Retry timing follows the download server's guidance
without exceeding the update's total recovery budget. Integrity failures still
stop before installation.

When an update cannot complete, the Computer page preserves a specific,
user-safe failure reason. A Service update failure only reports the Service
outcome; it no longer claims that the CLI is ready without evidence.

### Restore secure Windows CLI sign-in

The Windows CLI now loads the system encryption component before saving or
reading sign-in credentials. Credential-storage failures report a clear reason
and error code without exposing tokens or repeating the same error.

### Smoother new chats, activity navigation, and Settings

New Center Agent chats support attachment previews, paste and drop, and saved
attachment drafts. The first message appears while the chat is being created,
even when sidebar settings are still loading. Attachments added while an existing
chat loads keep their previews and carry over into the conversation.
Sending while attachments finish preparing preserves any newer draft and files.
Removed or sent attachments stay out of the composer when an older draft finishes loading.
The welcome area and first message stay in place as the new chat finishes loading.

Sidebar activity indicators open the conversation or Thread where the agent is working.
Completed work stays finished when you close a Thread, add replies, or return
to a conversation. An older reply no longer hides a newer run by the same agent,
and activity links continue to open work that is still active.
Center Agent chat links retain both the selected session and Thread.
Message previews in the sidebar link directly to the displayed message, including
Thread replies. Conversation menus have clearer labels and action icons.
Settings keeps its navigation and dialog in place while a section loads.
Spaces and direct messages keep the conversation sidebar, header, and centered
message and composer layout visible while loading. Saved Members panel widths
and open states also apply to the loading placeholder.

### Verify a local Agent before switching installs

When OpenMeld discovers a local Agent for the first time or you choose a
different installation during repair, it now verifies that exact installation
can start before saving it or reporting it ready. A failed or unfinished check
keeps the available choices visible; repair also preserves the current install
and its enabled setting so you can safely retry.
