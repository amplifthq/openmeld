# v0.3.124

Released August 28, 2026

## Improved

### Connect computers without waiting for Agent setup

Connecting a computer now finishes as soon as its OpenMeld Service is safely
running. Local Agents continue preparing in the background, setup commands stay
fresh while the Connect page is open, and OpenMeld automatically recovers more
stale Service installations without asking the user to diagnose them.

## Fixed

### Setup now reports the final Service state safely

Computer setup now finishes successfully after OpenMeld Service recovers from
a temporary start delay, and shows the Service as connected even when no local
agents are installed yet. Development, Staging, and Canary setup also stay
isolated from the published OpenMeld Service on the same computer.
