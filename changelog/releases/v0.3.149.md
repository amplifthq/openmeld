# v0.3.149

Released September 3, 2026

## Fixed

### Create and understand Agents without misleading gaps

New Agents now appear immediately at the top of their owner's list and show an
honest checking state while Wake availability loads, without briefly claiming
the Agent does not exist or cannot be reached. The local Agent picker also keeps
the user's latest choice instead of snapping back to an earlier selection.
Teammates can see the same safe Agent identity, avatar, public setup, and compact
activity summary whether the Agent is available, checking, or offline, while
private computer and local execution details remain owner-only.
