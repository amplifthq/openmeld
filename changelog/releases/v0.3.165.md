# v0.3.165

Released September 7, 2026

## Improved

### Clearer computer connection guidance

Computer setup shows short instructions for copying the command, opening Terminal,
and following the prompts. Connected computers have a direct management link,
while the standalone connection page remains available for adding a computer.
Center Agent chat offers management before starting another connection flow.

Create a Space and Show me around now add a suggestion to the composer without
replacing your draft or sending a message. You decide when to send. The computer
setup panel also has a close button and follows the surrounding card layout.

Computer Connection keeps automatic updates in its options menu and hides the
setting when its value cannot be read. Agent creation lists computers rather than
their historical connections; a single computer does not require a computer choice.
Technical connection selection remains available in advanced details when needed.

Optional computer details that fail to upload no longer undo a successful
registration. Registration alone still does not mean an Agent is ready to run.

## Fixed

### Clearer computer status and precise computer controls

Computer status distinguishes a live connection, a normal disconnection, and a
status that could not be checked. Saved computer records no longer count as proof
that a local agent can run.

Computer settings and CLI diagnostics target the selected computer and
environment. The Center Agent looks up the requesting teammate's local agents
instead of assuming the Organization owner's computer is the target.

CLI integrations must update for the new `computer list --view agent` payload:
`computers` includes explicit connection evidence and `isThisComputer` identifies
the local installation. This replaces the old routing-preference interpretation.
