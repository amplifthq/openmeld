# v0.3.262

Released October 15, 2026

## Improved

### Faster release checks with visible stage timings

Release checks avoid downloading unchanged deployment receipts and read
independent workflow histories concurrently. Automatic continuation reports
time spent checking status and running each component, so operators can locate
delays without repeating a deployment. Fresh evidence and release checks remain
required.

## Fixed

### Keep renderer releases within their selected scope

Website-only and Docs-only releases no longer require product database
inspection credentials. Nested builds can reserve their actual memory budget
without manually configuring an outer wrapper, provided current capacity and
memory pressure allow it.
