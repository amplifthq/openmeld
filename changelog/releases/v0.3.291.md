# v0.3.291

Released November 6, 2026

## Fixed

### Recover a slow Space file upload

Space file uploads from the CLI allow more time on slow connections and show
when the server has received each part. If the result is uncertain, you can
check the exact file and retry the same upload without creating another copy.
During long Local Agent tasks, the Agent is prompted to share milestones and
distinguish finished checks from evidence it still needs to deliver.

## Security

### Update the Windows helper's bundled runtime

The Windows process helper uses the patched .NET 10.0.14 runtime through SDK
10.0.403, addressing CVE-2026-111497. Build and release workflows use the same
pinned SDK and retain dependency vulnerability checks. The helper remains
self-contained, so users do not need to install .NET.
