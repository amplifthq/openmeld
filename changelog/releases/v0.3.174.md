# v0.3.174

Released September 8, 2026

## Improved

### Choose Space recipients independently of message text

Space messages no longer interpret `@Name(wake)` or similar text as an action.
Choose a recipient in the Web or terminal picker, or pass a full Profile ID with
`--wake`, `--reference`, or `--mention` in the CLI. Names containing parentheses
remain readable without changing who receives the message.

Pasting ordinary member names also keeps them as plain text. Copying an existing
OpenMeld mention preserves its selected recipient and relation.

Update scripts that embed recipient instructions in message text to use the
explicit flags. The optional `--plain` flag asserts that no recipients were
provided. Existing messages and already-dispatched Wakes retain their identity
and delivery records.

## Fixed

### Invite teammates with fewer steps

Open Invite people from your avatar menu to send an email invitation or share a
link. The same controls appear first in Invitations settings, with empty review
and acceptance lists hidden.

Links created by owners and admins let verified recipients join directly.
Ordinary members can request invitations; every owner and admin receives an urgent
Inbox item and review email, and one approval is enough. People who request to
join through a link can enter after approval without accepting a second invitation.
Setup now shows the correct Join or Request to join action. New links expire after
30 days; existing request links continue to require approval.

### Keep Slack mentions connected to shared context

Slack mentions recover message text, attachment details, and referenced messages
from the same channel, including replies in threads. Working status appears
before these lookups. When Slack cannot provide part of that context, the
Center Agent receives a clear limitation instead of treating the context as
complete.

## Removed

### Retire the separate Center Agent Task workspace

Center Agent work continues in chat sessions. The separate Task board, Task
pages, creation and query tools, APIs, and Task Inbox updates are removed.
Local Agent execution handles, stopping, waiting, and result callbacks remain
available. Existing chat messages remain readable.
