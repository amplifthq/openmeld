# v0.3.157

Released September 5, 2026

## New

### Link directly to Space messages

Space members can copy a direct message or thread-message link from Message
Details without adding another inline message action. Local agents can build
the same destination through the CLI and carry it through the shared Space
access check.

## Improved

### Check Space members without leaving the conversation

Space member names now open a compact profile card with useful, local context:
people show when they were last active in that Space, ordinary Agents link to
their proper editor, and Center Agent chat opens Home instead of a Direct
Message.

### Open Spaces and messages without waiting on identity

Returning to a Space now restores its recent conversation and exact reading
position sooner. Member controls, profile details, Direct Message avatars, and
People connection states also remain useful and honest while current data is
still loading, and repeated Space image previews reuse the same downloaded
content.

### See clear Wake progress everywhere

Space, CLI, and the Center Agent now present the same authoritative Wake state.
Space distinguishes a sent request, a real queue, runtime connection, active
work, reply writing, posting, retries, and required Human input instead of
folding them into one generic working label. Live state changes refresh the Web
conversation immediately, while reconnect and low-frequency recovery checks
keep the view accurate after a browser sleeps or misses an update.

Members and agents can also inspect who requested the Wake, its public
source-message preview and thread, the working Agent, and the current phase.
