# v0.3.284

Released November 1, 2026

## Fixed

### Keep Computer connection checks responsive during release-policy refresh

OpenMeld can report a registered Service and its Agent routes while the release
policy is still loading. The Service keeps pending connection history on the
computer when its connection closes and resumes uploads after the new connection
is acknowledged.

### Keep local Agent work safe through updates and recovery

Service updates preserve running work when shutdown cannot be confirmed and keep
task folders in place. Ordinary automatic updates yield if new work arrives
before the idle switch is admitted, keeping the same update ready for later.
Claude reply reviews use only context and delivery tools instead
of entering a new planning approval. Claude SDK processes now contribute the
evidence needed for safe recovery, and a failed Codex usage probe no longer leaks
an unhandled request rejection.

When Desktop is running with notifications enabled, a confirmed local sign-in
failure offers a quiet reminder to reconnect. Permission changes retain their
source and before/after settings in the owner's audit history.
