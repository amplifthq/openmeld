# v0.3.205

Released September 14, 2026

## Improved

### Keep creation actions in Spaces and Team

The global plus button is temporarily hidden from the main sidebar. Use the
Spaces menu to start a conversation or create a Space, and the Team menu to
invite members or create an Agent.

### Move on immediately after creating an Agent or deleting a Space

Agent creation now returns you to Agents as soon as you submit, with setup
progress while the request is confirmed. You can edit and retry an unfinished
request or dismiss its local card. Deleting a Space immediately opens Browse
Spaces and removes it from the lists. If deletion fails, the Space returns and
a persistent error includes a link to reopen it.

### Understand what each Agent permission mode does

Agent setup and settings now explain each controller permission mode in terms
of what the Agent can do and when it will still ask. Familiar mode names stay visible, while command-line details are folded
away until needed.

## Fixed

### Clear pending Wakes for deleted agents

Old pending Wakes stop retrying when their agent has been deleted. Spaces shows
a simple system message explaining that the Wake was cancelled, instead of
leaving it on "Trying to reach".

### Clearer waiting and working time for local Agents

When another app is using an Agent's conversation, Spaces explains why the
request is waiting and offers Cancel waiting. Working time starts when execution
begins, excluding time spent waiting. Stopping a request after it starts no longer
reports that it was still waiting for the conversation.

Waiting requests can also recover after the other Codex process exits abruptly,
even if it leaves a lock file behind.

### Open Inbox notifications at the exact message

Inbox notifications scroll to and highlight their exact Space message without
being pulled back to the latest message as the conversation finishes loading.
Older links load the message and its surrounding conversation directly, without
stopping after a fixed number of history pages. Opening a main-message link
closes the previously selected Thread so the destination has room to display.
Thread notifications open the Thread header and composer while replies load,
then bring the linked reply into view. Closing or switching threads while a
request is pending keeps your latest selection.

### Restore recent live reasoning after reconnecting

Spaces can restore an Agent's recent live reasoning when you refresh or reconnect,
without waiting for another reasoning update. The temporary tail is available
while the server retains it in memory; it is not saved in conversation history.

Live reasoning supports basic Markdown formatting and stays open while an Agent
switches between thinking and using tools. If you collapse it, new output keeps
it collapsed until you choose to open it again.

Reopening follows the latest reasoning. Turning off Local Agent reasoning sharing
also blocks reconnect replay without waiting for the owner's computer to respond.
