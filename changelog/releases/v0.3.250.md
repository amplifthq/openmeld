# v0.3.250

Released October 9, 2026

## New

### Choose Claude Haiku 5.5 for your Agents

Choose Claude Haiku 5.5 for Claude Code, Cursor, OpenCode Zen and Go, the Center
Agent, or a personal Remote Agent. Claude Code requires version 2.1.293 or later.
Your provider account must have access to the selected model.

Claude Code, OpenCode, and hosted Agents offer five reasoning levels. Cursor
uses its provider-defined model configuration. Existing default models and
saved selections stay the same.

## Improved

### Clearer privacy and service terms

OpenMeld's Privacy Policy and Terms explain local and hosted agent processing,
Agent Activity metadata, Center Agent memory, connected Apps and Channels, and
what account deletion removes or retains. The pages identify the service
provider and give direct links to both policies and the contact email.

### Download OpenMeld directly from the website

Choose macOS or Windows in the website's Download menu to start downloading the
latest available build. All downloads opens a public overview on openmeld.ai.
The website's single download page includes version numbers, file sizes, and
installation instructions. Existing App download links redirect there and
preserve the selected build. Windows builds are labeled Preview; macOS is not.

## Fixed

### Cleaner OpenMeld icons and reusable brand assets

OpenMeld's macOS app icon and browser icons have cleaner edges and adjusted
visual alignment. The macOS app, Web, Website, and Docs use assets from the same
generated brand set. Transparent and solid-background wordmarks are available
for light and dark backgrounds.

The documentation header uses the official wordmark. Select the logo to open
the main website, or select Docs to return to the documentation home page.

### Consistent Agent avatars in Spaces

The Center Agent avatar preview now matches its colors in Spaces. Avatars that
use Appearance colors no longer show Original as a saved choice. Selecting
Original saves that color choice for the Agent. Appearance also retains its
Original and Balanced color selections.

New Agent Direct Messages now show the current Agent avatar in the sidebar as
soon as the conversation opens. Remote Agents use the selected model provider's
logo without waiting for a later directory refresh.

### Keep your selected avatar colors

Original and Balanced avatar palettes stay selected when you reopen Appearance.
The landing page demo uses Original colors to match its introduction. Cloud
avatars use a lighter neutral white while keeping their textured finish.

### Keep your time zone when replying in a thread

Thread replies now use your observed time zone and the time OpenMeld received
your message. Relative dates and delays keep that original time when delivery
waits or retries.

### More reliable task follow-up and local time

Cloud Computer commands keep their recorded exit results when file synchronization
loses its connection. Slow command checks have a time limit, and one stuck check
no longer holds up the other commands. Agents can inspect the retained result
before deciding what to do next.

When a Space coordinator cannot finish because a retained Computer command was
lost, the Center Agent can make one restricted attempt to summarize the completed
Agents' published results. This does not restart their work or override Stop.

Web, macOS Desktop, and Local Service share the same user time-zone record. Remote
Agents receive that time zone, the original request time, and a fresh current
time for each model request. Queued messages retain their original time context.
Local Agents are guided to use the user's local environment
unless the task calls for Cloud Computer.

### Slow repeated background retries during service failures

Failed background cleanup and execution-recovery steps now wait progressively
longer before retrying, reducing unnecessary cloud activity during persistent
failures. Healthy work can continue, pending work is retained, and normal retry
timing resumes after recovery.
