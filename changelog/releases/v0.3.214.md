# v0.3.214

Released September 20, 2026

## New

### Hand off selected Space files to another Agent

Hand off specific file and Skill versions with a goal and next steps. Agents
save changes as revisions of the original Space files and choose which results
to include in their reply. Managed local working copies preserve edits when
uploads fail or another collaborator changes the same file.
Conflicts can be resolved by comparing the shared version, merging local edits,
and saving again without replacing another collaborator's work silently.

The first version uses existing hosted Computers and macOS Codex App Server
for local continuation. It does not create a private user-owned Computer or
automatically synchronize folders.

## Improved

### A calmer Inbox for conversations, requests and device updates

Inbox separates mentions, actions and reviews. Combine People or Agents with
Direct messages or Spaces in one filter menu, and keep Unread only beside the
tabs. Conversation groups keep routine activity compact while important open
requests remain easy to find. Blue and yellow indicators distinguish unread
updates from priority attention without turning every approval into an alarm.

The first outside contact with your personal Agent gets one awareness reminder;
routine follow-ups do not keep interrupting you. Unexpected Computer connection
loss and native Desktop updates use the same Inbox, with device-specific recovery
or update guidance and no duplicate copies when you switch organizations.

Desktop's menu bar keeps the logo and unread indicator close together, with
native macOS contrast instead of a fixed badge color.
Mentions and priority attention retain distinct @ and ! counts, while ordinary
unread stays a quiet dot without a number.

### Clearer page loading and Agent usage at a glance

Agent pages retain navigation while their content loads, with placeholders
matching the sections being fetched. Provider usage appears beside Agent
configuration cards, using the familiar quota ring and clear reset information.

Computer inventory no longer waits for a duplicate routing-preference request.
Other independent sections, including channel connections and personal Computer
lists, can appear without waiting for unrelated data. Settings, histories, and
lazy Space panels use local placeholders rather than bare loading text. Unknown
preferences no longer appear as saved defaults while their values are loading.

### Find shared Skills in Team

Skills now live beside People, Agents, and Plugins in Team. Members can browse
the workspace's shared working methods without opening a Center Agent
conversation, and existing Skill links still reach the right page.

Find skills in a compact, searchable list with a status filter. Open a skill to
read or edit its instructions immediately; supporting files, optional properties
and version history stay close without crowding the document. Save remains
explicit and easy to reach. Creation and GitHub installation guide you through
the existing actions, protect unfinished input, and open the result directly.

Switching workspaces opens that workspace's catalog rather than carrying a
Skill from the previous one. Editing retains unsaved-change protection and the
release version on which a draft was based, including during background updates
and browser history navigation. Existing editing and management permissions
remain unchanged.

Instructions and Markdown references now refresh together with accepted saved
versions without replacing unsaved work. When a save succeeds while more edits
arrive, the leave dialog explains that the previous changes were saved and the
newer changes still need saving, rather than reporting a save failure.

## Fixed

### Clearer Desktop update status and reminders

Desktop update reminders now point from Settings to Updates with matching blue
indicators. The Updates page puts the current result and next action first, and
the compact reminder offers a full-width action with Later at the top right.

Downloads show their actual progress, repeated checks do not revive dismissed
reminders, and errors explain the appropriate recovery step. Download and restart
remain separate choices, with existing draft and installation protections intact.
