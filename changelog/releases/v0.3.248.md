# v0.3.248

Released October 8, 2026

## New

### Learn OpenMeld in a real Space

New and existing users now get a tutorial in a real Space. Add your Center Agent,
send a prepared greeting, and read its reply. Progress is saved; Help has one Tutorial
entry with Continue and Replay. Replay creates a new Space when you confirm.
Computer setup, Plugins, and Routines stay optional. Organization owners and
admins also get links to Channels, invitations, and team context. Members see
only the actions they can use. Closing a tutorial dialog saves your place so you
can continue later. The former onboarding remains in source without an entry.

## Improved

### A simpler loading screen

Web first-run and Desktop startup now show the same centered OpenMeld Logo.
The Logo responds to the pointer, with a static appearance when reduced motion
is enabled. Loading text and the line below the Logo are removed.

### Center Agent reconnects after temporary model failures

Center Agent retries temporary model failures up to five times with increasing
delays. The conversation shows Reconnecting and the retry count while keeping
your progress and Stop control available. Work continues in the same task when
the connection recovers. If all retries fail, the task reports a failure.

### Choose how the history slider appears

Appearance now includes Show and Hide preview cards for the history slider.
The slider uses less space beside messages and leaves no empty lane in
conversations without older history to browse.

### Clear Inbox requests with less effort

Ended Agent approval, plan review, and question requests no longer leave an
unread dot or ask for a response. Their history stays available. Failure notices
and final results stay unread until you read them.

Mark as read responds immediately for individual items and groups. Individual
items now show the action beside the three-dot menu. If saving fails, Inbox
restores the affected read state without undoing other successful reads.

### Clearer Space files and larger image previews

Space Files now includes chat attachments by default. Image previews use the
available space in Columns and Gallery, and List shows small image thumbnails.
Loading placeholders no longer show a second white document frame. File details
have more room, and ordinary file operations reuse unchanged image content.

The file toolbar no longer includes the structured Send to agent handoff form.

### Continue paused work from the conversation

Continue an occupied conversation on a new branch or skip paused work from the
existing message queue. Requesters can manage their own paused work when the
operation does not affect other people's work or require shared write access.
Sorting, Send now, editing, and deletion keep
their familiar controls. Untouched queued messages follow a new branch without
resending messages whose delivery is uncertain.
Send errors appear beside the send button, with room to wrap on small screens.

Codex work can continue automatically after an occupied-conversation wait when
OpenMeld confirms that no turn started and the task cannot modify shared files.
Tasks that need an owner's decision keep the existing recovery choices.

Shared Spaces keep each person's follow-ups attached to their own response.
One person's pending messages no longer hold up another independent task.
Send now is available only while that response is running. Waiting for another
app is shown separately from waiting for earlier tasks.

Center Agent chats use the same Queue. Follow-ups can enter it while the first
request starts, without appearing as a second running task.

### Create from sidebar shortcuts

Start a new message or create a Space from the Spaces sidebar menu. The Team
sidebar menu also offers New Agent. These shortcuts sit below a divider and
open the existing creation flows.

### Faster Space tabs and Discover cards

Spaces tabs switch content without waiting for navigation requests to finish.
Space cards avoid rendering duplicate member avatars when the layout changes.
Discover now offers Cards and Table, with the same view preference across all
three tabs. You can preview and join a Space from either view.

### Inbox filters respond immediately

Inbox tabs, Unread only, and activity and conversation filters now respond
without waiting for page navigation. The selected view shows its own loading
state while new results arrive. Filter combinations and browser back and forward
continue to work, including older unread-only links.

### Less repeated setup during Agent work

Hosted Agents can recover recently selected tools across multiple steps after
context compaction. Clearer guidance helps them reuse existing evidence and
continue pending work. Directory reads with only a new response timestamp no
longer count as new information for repeated-read protection.

### Less repeated work when browsing Team

Team tabs begin loading when you point to them or reach them with the keyboard.
Profile avatars reuse their rendered backgrounds when you move between pages,
reducing repeated drawing in member lists and cards.

### More room in full-width conversations

Full-width conversations and Threads now use the same compact side spacing
for messages and composers. Centered conversations keep their existing layout.

### Reduce Inbox loading work

Inbox performs less repeated work when loading larger notification histories.
Access checks, grouping, unread counts and pagination keep the same behavior.

### See your new Space while it is being created

Creating a Space opens its conversation immediately, with its name in the header
and sidebar. You can write a message and add attachments while it prepares.
Messages submitted during preparation send after the Space is ready. If creation
cannot be confirmed, your draft stays available in the conversation.

Starting a Space from New Message now uses the same immediate conversation.
New agents are selected as soon as creation completes, without waiting for the
people list to refresh. Adding members closes the picker immediately and shows
progress in the Space. If adding members fails, you can retry in the same Space.

### Smoother AI usage tabs

Switching between Organization usage and My agents now reuses the usage charts
instead of rebuilding them. Your selected period and expanded details stay in
place while each view loads its own data.

### Theme cards and a full settings page

Appearance settings again offers three theme cards for Light, Dark, and System.
The account menu keeps its compact theme selector.

Use the expand control beside Close in App settings to open the current section
as a full page. The page uses the same settings controls, and AI usage keeps your
selected usage view.

## Fixed

### Cancel and retry Desktop update downloads

You can cancel an update download and try again. Downloads that stop making
progress show a retry option instead of remaining stuck at the same percentage.
Desktop installers and updates use a cached download service that supports
partial file requests. Installing an update still requires your restart action.

### Confirm Agent responses after a connection timeout

Space approvals and answers now check whether a response was saved when its
confirmation is lost. If the result remains unknown, a clear status and check
action replace the misleading failure message. Inbox updates no longer delay
sending a saved response to the Agent.

### Distinguish message links from message text

Copy link now uses a link icon in message action menus, so it is easier to
distinguish from Copy message.

### Keep Agent logos visible when the sidebar is closed

Codex logos in Space cards no longer turn into blank white tiles when the
sidebar is closed. Repeated Agent logos now keep their own color definitions,
so hiding one copy does not affect another.

### More reliable Codex session discovery and queued Wakes

Codex session discovery now handles repeated native task records and uses the
task's update time. The Computer page shows discovery problems and keeps each
page of results scoped to the selected computer. Personal Remote Agents can
find and request session history under the existing owner access settings.
Personal Agents no longer need Center designation to list conversations.

Queued local Wakes use refreshed working-folder information after a Service
connection refresh, while retaining the existing authorization checks.

Hosted Wakes keep retrying the same request when submission cannot be confirmed,
instead of entering a waiting state that blocks admission recovery.

Computer conversation access now uses one switch and selected projects, without
a per-Agent list. Settings stay directly editable on the Computer card and save
immediately. Conversation browsing and recent access open in one full-height
drawer, with messages in the same drawer.
Existing per-Agent grants stay off until you enable the new
setting; other members still cannot read your history.

The same access settings now cover Claude Code, OpenCode, and Grok Build
conversations as well as Codex. Each conversation shows its source. People and
agents use the same read-only operation. Cursor and Antigravity history remains
unavailable.

### More reliable Wake session renewal and clearer blocker updates

Wake session renewal no longer rereads a verified, unchanged credential from
secure storage. A temporary Keychain failure therefore does not interrupt that
renewal. New credentials still require storage verification, and remote access
checks remain in place.

Wake instructions now tell agents to share meaningful blockers in the Space
and end with a clear explanation when work cannot continue. Repeated approval
delivery no longer logs another local resume. Cloud Computer help includes
capability discovery and valid operation examples.
