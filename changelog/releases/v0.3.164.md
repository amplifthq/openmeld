# v0.3.164

Released September 7, 2026

## Improved

### Retire completed Remote Agent rollout fallbacks

Remote Agent now requires the current Core contracts for Slack results,
Message Channel account linking, and connected App progress. It no longer
downgrades requests or progress metadata for older Core versions. Keep Core
current before deploying this worker; roll back Remote Agent first when
reverting those Core contracts. Existing local clients and saved conversation
formats are unchanged.

## Fixed

### Keep existing chats writable after the preview upgrade

Existing chats now create the message preview counter during their database
upgrade. Sending a message no longer fails because the chat already completed
an earlier database version. Existing messages and preview ordering are preserved.

### More reliable command reconnection and directory reads

Center Agent can detach from a command while its output connection is still
opening without trying to open that connection twice. Detaching does not stop
or restart the command.

Large organization directories can be read in bounded pages, preserving member
and Agent details with explicit totals and continuation cursors. The Agent must
finish the pages before treating a roster or identity match as complete.
