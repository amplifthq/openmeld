# v0.3.111

Released August 26, 2026

## Fixed

### Let Agents reply without a shell approval prompt

Agents can now choose and record a Space reply, final status, or silent outcome
through a dispatch-scoped OpenMeld tool without asking the member to approve an
OpenMeld shell command. This does not relax the Agent Profile's normal Codex
permissions. Multi-paragraph replies also preserve real line breaks, literal
`\n` text, quotes, backslashes, emoji, and shell-like characters without
rewriting the message. The dispatch-scoped CLI remains available as a fallback
and for replies with attachments.

### Prevent incompatible Local Agent model choices

When a selected Local Agent installation clearly cannot run a model, OpenMeld
now disables that model while an Agent Profile is created or edited. The dialog
explains why and links directly to the Computer where the member can update or
change the installation. Missing compatibility information does not block the
member or make OpenMeld guess. Existing Agents that hit the same problem during
a Wake now get the same direct Computer recovery path.
