# v0.3.233

Released October 1, 2026

## New

### More models for local and hosted agents

You can choose Claude Sonnet 5.5 for Claude Code and Cursor Agent Profiles,
and Claude Opus 5.5 for Cursor. OpenCode adds more GPT-6 choices and Fast
variants, along with LongCat 2.5 Preview Free and Space Bunny Free.

Center Agents and personal Remote Agents gain Claude Sonnet 5.5, GPT-6.1 Sol,
and GPT-6.1 Sol Pro. Availability depends on the selected channel, installation,
and account access. Existing model choices and defaults stay the same.

## Improved

### Clearer model labels and another Center Agent option

Model selectors show New for the latest reviewed releases, including GPT-6.1
Sol and Claude Sonnet 5.5. Older models such as GLM 5.3 Flash no longer carry
the label. The CLI's offline catalog also drops its old GLM label.

Center Agents and personal Remote Agents gain GPT-6 Astra (Pro mode) as an
additional option. GPT-6.1 Sol (Pro mode) and GPT-6 Astra (Pro mode) are labeled
as modes of their underlying models. Existing selections and defaults stay the
same.

### Desktop 0.1.15 for Mac and Windows preview

Desktop 0.1.15 is available for Apple silicon Macs and as an internal Windows
x64 preview. Both include the latest Space, Inbox, and Team interface updates.
OpenMeld CLI and Service 0.3.233 are also available.

The Mac download is signed and notarized. An installed 0.1.14 app was upgraded
to 0.1.15 through its updater and restarted successfully.

The Windows installer is unsigned and has no automatic updates. Native package
and runtime checks passed; installed Windows GUI acceptance remains unverified.
An existing PowerShell task-host compatibility fixture still times out.

Download [Mac Desktop](https://openmeld.ai/desktop?platform=macos-arm64) or the
[Windows x64 internal preview](https://openmeld.ai/desktop?platform=windows-x64).

### More complete local agent usage

Computers can show usage from supported Claude Code accounts, Cursor CLI logins,
and OpenRouter accounts connected through OpenCode. Grok Build correctly shows
unused capacity when its billing response omits a zero value. Missing usage now
distinguishes sign-in requirements, unsupported account capabilities, unreported
limits, and failed refreshes.

Usage availability still depends on the account and provider. Observational
sources show capacity without preventing otherwise ready agents from starting.

### Right-click shortcuts across Inbox, Spaces, and Team

Right-click conversations, messages, Inbox items, and Team resources to open
their common actions. Pin conversations, copy links, mark Inbox items as read,
star people, and reach existing Agent, Skill, and file actions from the item
you are working with. Menus use the same actions and permissions as their
existing controls, with consistent pointer and keyboard behavior.

### Smoother sidebar display menu

The sidebar display menu uses Fluid Hover to keep one highlight under the
nearest choice as you move the pointer. Its padding follows the highlighted
choice when clicked. Keyboard navigation and reduced motion remain supported.

### Start Codex Agents with GPT-6.1 Sol

New Codex Agents start with GPT-6.1 Sol and Medium reasoning unless you have
saved a different creation preference. Existing Agent model selections stay
unchanged.

## Fixed

### Enable prompt caching for supported hosted models

Hosted Agents using Claude or supported Alibaba models can reuse identical
instructions, tool definitions, and conversation context through prompt caching,
reducing repeated input costs while keeping the selected model and full context.
Models with automatic caching keep their existing behavior. Savings depend on
provider cache hits.
