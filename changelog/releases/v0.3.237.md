# v0.3.237

Released October 3, 2026

## Improved

### Less database work for Inbox and safer history cleanup

Inbox counts and grouped views use less database work while continuing to check
current access. Bulk read and removal still apply only to the view you selected.
Collapsed update groups now share the same subtle hover highlight as Inbox items.

Activity cleanup can process larger backlogs without double-counting sessions.
Old Wake diagnostics can expire without deleting in-progress work, recovery
records, or the records needed to honor a stop request.

### Lower context overhead in long Center Agent conversations

Center Agent compacts long conversations earlier for reviewed models with higher
long-prompt prices, without changing the model you selected. Large tool results
use shorter previews with permission-checked access to retained details. The
usage ledger separately identifies compaction costs while Usage totals remain
compatible with existing clients.

## Fixed

### Clearer progress while agents keep working

Center Agent tasks that continue after delegated work now show tool progress
and reply text in Spaces and direct messages. Active requests no longer switch
to "Still waiting for the final status" just because no visible update arrived
for 45 seconds. Progress follows the actual task state, with Stop and message
details still available.

### Continue Codex conversations with compatible preview builds

Compatible Codex preview builds can continue existing conversations without
being incorrectly blocked by a tool-policy error. Local Agent capability checks,
model compatibility, and update advice now share semantic version handling,
including preview and build suffixes. Existing permission checks remain in place.

### Keep your place when returning to a conversation

Returning to a conversation keeps you at the latest messages if you left it at
the bottom, or at your saved message if you were reading earlier history.
Page navigation no longer overwrites the conversation's restored position or
an explicit message jump with old scroll coordinates.

### More reliable Inbox actions and failure reminders

Old automatic-continuation failures are repaired when Inbox refreshes, removing
incorrect requests for action and opening the failure in its original conversation.
Read and removed states are preserved.

Agent permissions, questions, and plan reviews retain a response receipt after
delivery. Retrying the same answer is safe; a conflicting answer is rejected,
and a handled request cannot reappear as a new approval.
