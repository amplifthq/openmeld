# Support

## Find a guide

Start with the [documentation](https://docs.openmeld.ai) or
[troubleshooting guide](https://docs.openmeld.ai/docs/help/troubleshooting).
For source changes, use [Contributing](CONTRIBUTING.md).

## Report a bug or request a feature

Search [existing issues](https://github.com/amplifthq/openmeld/issues) first.
Then [report a bug](https://github.com/amplifthq/openmeld/issues/new?template=bug_report.yml)
or [suggest a feature](https://github.com/amplifthq/openmeld/issues/new?template=feature_request.yml).

Include your OpenMeld version, operating system, and steps to reproduce a bug.
State what you expected and what happened. For the CLI, use `openmeld --version`.

Remove setup tokens, API keys, cookies, account details, and private work from
logs and screenshots before posting. GitHub issues are a public support channel.

## Keep sensitive reports private

- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md).
- **Harassment or community conduct:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- **Private account or billing questions:** email [felix@amplift.ai](mailto:felix@amplift.ai).

Community support does not include a guaranteed response time.
