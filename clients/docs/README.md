# OpenMeld Docs

Independent public documentation Worker for OpenMeld product guides.
Pages are grouped into Start, Work, Team, Help, and Reference.
Production pages allow indexing. Development and staging remain `noindex`.

The foundation uses the official `tanstack-start` template generated by
`create-fumadocs-app@16.2.16`, Fumadocs Core/Base UI 16.16.2, and MDX 15.4.6.
TanStack Start, React, Vite, and Wrangler follow the workspace versions.
Cloudflare's Vite plugin replaces the template's Nitro/Vercel adapter.

From the repository root:

```sh
pnpm install --frozen-lockfile
pnpm --filter openmeld-docs dev
pnpm --filter openmeld-docs check
pnpm --filter openmeld-docs cf-typegen
pnpm dev:run -- node scripts/release/production-artifact-check.mjs --scope docs
```

Local preview: `http://127.0.0.1:3600/docs`. Use a free port with
`pnpm --filter openmeld-docs dev --port <port>` in concurrent worktrees.
Stop the foreground server with Ctrl+C.

Content lives in `content/docs`. The official loader owns the page tree,
search index, processed Markdown, `/llms.txt`, and `/llms-full.txt`.
The build prerenders linked pages and retains a Worker for search and Markdown.
Shared brands and fonts come from `@openmeld/ui`.

Production: `docs.openmeld.ai` / `openmeld-docs-prod`.
Staging: `docs.staging.openmeld.ai` / `openmeld-docs-stg`.
No database, authentication service, or application secret is required.
Use the guarded `docs` release scope. Package deploy commands are stage
implementation details, not alternative release entrypoints.

Ownership and UI extension rules: [Docs](../../developing/clients/docs.md).
