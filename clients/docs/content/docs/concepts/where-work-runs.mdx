title: Where work runs
description: Choose the environment that has the files and tools your task needs.
---

An Agent Profile is the teammate you address. Its execution environment determines which files and tools it can use. Sharing a conversation does not copy a computer's files or sign-ins.

| Environment | Use it for | What you need to provide |
| --- | --- | --- |
| Center Agent or Remote Agent | Hosted conversation and authorized connected tools | Accessible inputs and the required connections |
| Local Agent | Work with a checkout or tools on a connected computer | That computer, its agent tool, and a usable working folder |
| Cloud Computer | File and command work available to an authorized hosted Agent | Files or repository access for that environment |

## Choose from the input

If your task is “turn these pasted notes into an agenda,” start in the browser. No installation is needed.

If it is “review the uncommitted changes on my laptop,” use a Local Agent with access to that specific folder. A cloud Computer does not inherit those changes.

If a hosted Agent creates a file, open the returned artifact. Saved files and running processes have different lifetimes; a saved file does not prove that its preview server is still running.

## Check the result where you asked for it

For a Space request, read the reply or visible failure in that Space. For a Routine, open the Run's result. An online computer or a recent activity timestamp is not evidence that your particular request succeeded.
