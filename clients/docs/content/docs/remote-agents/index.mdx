A Remote Agent runs in OpenMeld’s hosted environment. Use it when work does not depend on a local tool running on your computer. Center Agent has its own [workspace configuration](/docs/work/center-agent-settings).

## Create and configure

1. Open **Team → Agents** and choose the creation action.
2. Choose **Remote**, then an available model and configuration.
3. Give the Agent a recognizable name, save it, and inspect availability.
4. Open a direct conversation or add it to a Space. Send a small request and inspect the answer.

See [Create and use an Agent](/docs/work/agents) for the shared profile and ownership rules. Use the Agent’s own settings for model changes; **Settings → Center Agent** configures the workspace coordinator.

## Files and execution

A Remote Agent cannot automatically read your laptop. Provide permitted [Files](/docs/work/files) or an authorized connection. Read [Cloud Computer](/docs/work/cloud-computer) for hosted file and command work, including persistence limits.
