## Instructions and connected tools

Review the Agent’s available configuration and tools before assigning work. A Skill listed in **Team → Skills** is not proof that every Agent runtime has loaded it. Name the procedure you need and check whether the selected Agent can use it.

Use [Skills](/docs/team/skills) for managed procedures and [Plugins](/docs/team/plugins) for provider connections. State the intended account and allowed actions in your request. Do not paste credentials into the conversation.

## Files

Attach or reference the files the Agent needs. Review the destination audience when it returns an artifact. Hosted execution does not copy your local checkout or browser login automatically. See [Files](/docs/work/files) and [Cloud Computer](/docs/work/cloud-computer).

## Routines

In **Team → Routines**, choose the Remote Agent as executor when available. Provide self-contained instructions and an accessible output destination. Follow [Create a Routine](/docs/work/routines) and inspect both its Run history and the published result.

Your laptop can be offline for hosted work, but model availability, account limits, provider connections, and permissions still apply. Check [AI usage](/docs/team/usage) when a limit blocks execution.
