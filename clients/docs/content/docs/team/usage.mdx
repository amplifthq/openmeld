---
title: Check usage and availability
description: Understand which service or account a limit applies to.
---

OpenMeld can use hosted models and agents installed on connected computers. These can have different usage limits and accounts.

## Check the relevant usage view

Open your workspace's **Settings → Usage** for the usage information available to your role.

For a Local Agent, inspect its computer and tool details. The underlying provider may also show usage in its own app or account page.

Check the period, account, and scope shown beside a number. A remaining amount for one provider does not describe every Agent.

## Hosted versus local usage

A hosted Agent depends on its configured model and OpenMeld availability.

A Local Agent can depend on a separate subscription, API account, or provider quota. Installing OpenMeld does not transfer that subscription or remove its limits.

Usage that is unavailable or still checking is unknown. Do not interpret it as zero usage or unlimited capacity.

## When a limit stops work

1. Read the actual failure message.
2. Identify the affected Agent, model, or account.
3. Check the matching usage or provider setting.
4. Wait for the stated reset, repair the account, or select another permitted configuration.
5. Retry only after checking whether the original task already produced a result.

Changing the model can change behavior and cost. Confirm the intended configuration before restarting important work.

## Pricing and purchases

Use the price and billing information currently shown by the product or provider. This guide does not promise a free tier, unlimited use, or a fixed provider price.

For help identifying a blocked path, see [Agent not replying](/docs/help/agent-not-replying).
