---
title: Access, sharing, and permissions
description: Check who can see the work and what an Agent is allowed to do.
---

OpenMeld separates workspace membership, conversation access, file location, and tool permissions. Check each one for the task you are doing.

## Check the audience first

Before sending a message or attaching a file, check the active workspace and conversation members.

A team member may be allowed to read Team files but not a private Space. A Space guest may see a copied Space file without gaining access to all Team files.

Copying content into a broader audience is a sharing action. Later deleting the source does not remove independent copies.

## Distinguish discussion from execution

A human mention draws attention. **Mention only** refers to an Agent. A **Wake** asks an Agent to work.

Inviting an Agent, assigning a Task, or accepting a recommendation does not grant unlimited permission to make changes.

State the action, target, and limits when asking for consequential work.

## Review tool identity

For external actions, check the connected account or Organization identity. Personal and shared credentials have different owners.

An admin role does not automatically grant access to another person's private agent context or personal account.

## Local Agent permission settings

A Local Agent uses its selected tool, computer, working folder, and permission mode. Review those choices before allowing it to change files or run commands.

A connected computer is not proof that every tool is signed in or that a specific Agent is available.

## Information protection

Owners and admins can add classification hints under **Settings → General → Information protection**. Use category names or document types, not secret values or sensitive records.

These hints guide information handling. They do not grant tool access or replace the built-in protection rules.

For legal terms and data policy, read the current [Privacy Policy](https://openmeld.ai/privacy) and [Terms](https://openmeld.ai/terms). This guide explains product controls; it does not add contractual guarantees.

## When access changes

A removed member or disconnected tool can make an old link unavailable. Ask the owning person or admin to review access. Do not share session cookies, setup grants, or credentials as a workaround.
