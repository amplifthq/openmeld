A Local Agent uses a supported coding tool on a connected computer. The Agent Profile, computer connection, tool login, and working folder are separate parts of setup.

## Get connected

1. [Set up a supported tool](/docs/start/local-agents) and complete its provider sign-in.
2. [Connect your computer](/docs/start/connect-computer), or [copy a prompt for your agent to help](/docs/start/connect-with-agent).
3. [Create a Local Agent](/docs/work/agents) with that computer and tool.
4. Check its [Project and working folder](/docs/work/projects).
5. Try a [small code review](/docs/tasks/local-code) and inspect the actual result.

## Keep it available

The computer and local tool must remain available when work runs. Sleep, shutdown, network loss, or expired provider sign-in can interrupt execution. Use [Computer help](/docs/help/computer) for connection and update problems, [Working folder help](/docs/help/working-folder) for missing checkouts, and [Agent not replying](/docs/help/agent-not-replying) for blocked work.

Review [Permission modes](/docs/security-and-privacy/permission-modes) and [private information protection](/docs/security-and-privacy/private-information) before sharing local work.
