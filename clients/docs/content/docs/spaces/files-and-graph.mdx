## Files

Open the conversation’s **Files** tab to find its attachments and artifacts. Check the conversation audience before adding a file. These files are separate from the complete **Team → Files** library.

Follow [Share and find files](/docs/work/files) for uploads, copies, revisions, and recovery. Copying a file to a Space creates a separate copy; later edits to its source do not update it.

## Graph

Use **Graph** to explore the conversation’s work visually. Return to the source message or Task to read the request, review the result, or continue the discussion.

A graph relationship or status display is not proof that an external action completed. Inspect the linked artifact or actual destination.

## Tasks and messages

Use [Tasks](/docs/work/tasks) for tracked deliverables and [Messages and Threads](/docs/work/messages) for discussion. Switching tabs does not change the conversation’s access rules.
