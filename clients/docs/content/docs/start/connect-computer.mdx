---
title: Connect your computer
description: Let OpenMeld reach the local agents and files on the computer you choose.
---

Connect a computer when you want a local agent to work there. You can use hosted Center Agent conversations without this step.

Want your local AI tool to handle the commands? [Connect with an agent](/docs/start/connect-with-agent) has a prompt you can copy into Codex, Claude Code, or another tool that can run commands on this computer.

## Before you start

Use the computer where the work should run. Sign in to the correct OpenMeld account. [Set up a supported Local Agent](/docs/start/local-agents) and complete its sign-in or provider setup. OpenMeld does not replace the tool's account or subscription.

## 1. Open computer setup

In Center Agent, choose **Connect my computer**. You can also use the computer setup step during onboarding. To manage existing connections, open **Search or run a command** and search for **Computers**.

If OpenMeld shows an existing computer, check its name. A connected computer in your account might be a different machine.

## 2. Copy your setup command

Choose the correct operating system and copy the command shown in OpenMeld. This command connects the computer to your signed-in account.

Keep this page open. Do not share the command: it can contain a short-lived account authorization. If it expires, get a new command from the setup page.

## 3. Run the command

Open [Terminal or PowerShell](/docs/start/terminal). Paste the complete command and press Enter.

Follow the instructions in the terminal. Return to the setup page when it reports that the computer is connected.

## 4. Check the result

Look for **Computer connected** and confirm the computer name. Local agents can continue syncing in the background after this appears.

Open the computer's details to check its **Local agents**. A tool that needs sign-in or repair stays unavailable until you resolve that condition. Finding the tool on disk is not enough.

## 5. Create or select an Agent

An Agent Profile is the named teammate you talk to in OpenMeld. [Create a Local Agent](/docs/work/agents), choose this computer and its local agent tool, then select the intended folder or Project.

Before assigning work, check the Agent's current availability.

## Keep the computer available

Local work needs the computer and its connection. Sleep, shutdown, network loss, or signing out of the underlying agent tool can interrupt availability. Hosted agents have a different execution path.

Connected computers can keep OpenMeld Tools up to date. Review **Keep OpenMeld Tools up to date** in the computer's Tools card.

If setup fails, use [Computer connection help](/docs/help/computer). Avoid resetting your local state as a first step.
