---
title: Set up a Local Agent
description: Install a supported tool, sign in, and connect it to OpenMeld.
---

A Local Agent uses a coding tool on a connected computer. Install the tool on the computer where the work should run. OpenMeld does not replace the tool’s account or subscription.

You do not need a Local Agent for the [browser Quickstart](/docs/start/quickstart).

## Choose your tool

- [Codex](/docs/start/local-agents/codex): Use an existing Codex installation or install the CLI, then connect it to OpenMeld.
- [Claude Code](/docs/start/local-agents/claude-code): Install Claude Code, finish sign-in, and make it available to OpenMeld.
- [Cursor CLI](/docs/start/local-agents/cursor): Connect Cursor’s command-line agent to OpenMeld.
- [Grok Build](/docs/start/local-agents/grok-build): Prepare Grok Build for local work through OpenMeld.
- [OpenCode](/docs/start/local-agents/opencode): Install OpenCode and connect a model provider before using it with OpenMeld.
- [Antigravity](/docs/start/local-agents/antigravity): Set up Antigravity CLI for local work through OpenMeld.

## From installation to your first result

Want help with the connection step? [Copy a setup prompt for your agent](/docs/start/connect-with-agent).

1. Follow your tool’s guide above and complete its sign-in or provider setup.
2. [Connect your computer](/docs/start/connect-computer) to OpenMeld.
3. Check **Local agents** in that computer’s details. Resolve the displayed reason if your tool is unavailable.
4. [Create a Local Agent](/docs/work/agents) and choose the computer, tool, and [working folder](/docs/work/projects).
5. Send a small request, such as the [code review example](/docs/tasks/local-code), and check the actual reply.

Already installed a supported tool? Check its availability in OpenMeld before installing another copy. A detected executable, a connected computer, and a completed task are separate results.

## If setup fails

Use [Computer help](/docs/help/computer) for connection problems or [Agent not replying](/docs/help/agent-not-replying) when a request has no result. Complete provider sign-in in the tool itself, then check again in OpenMeld.
