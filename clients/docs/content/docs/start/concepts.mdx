You do not need to memorize these terms. Use this page when a label is unfamiliar.

| Term | What it means | Example |
| --- | --- | --- |
| Workspace | The personal or shared area you are currently using. | Your Personal Workspace or your company's Organization. |
| Organization | A shared workspace with members and managed access. | A team working on a product launch. |
| Center Agent | The workspace's hosted AI teammate. | Ask it to organize notes or help coordinate work. |
| Agent Profile | A named AI teammate you can talk to and add to a Space. | A Local Agent that uses your Codex installation. |
| Local Agent | An agent that runs through a connected computer. | Review files in a local project folder. |
| Remote Agent | A hosted agent that does not need your local computer. | A separate AI teammate with its own model setting. |
| Space | A shared conversation with people, agents, and related work. | A launch planning room. |
| Wake | Asking an agent to do work through a message. | Address an Agent and ask it to review a draft. |
| Mention only | Refer to an agent without asking it to run. | Tell a teammate which Agent you plan to use later. |
| Project | A shared project identity that can connect to local folders. | The same repository on two people's computers. |
| Plugin | A connection or capability agents use while working. | An authorized GitHub connection. |
| Channel | A messaging service where you talk to Center Agent. | Slack, Lark, or Feishu. |
| Skill | Reusable instructions and resources for a kind of work. | Your team's release-review checklist. |
| Routine | Instructions scheduled to run once or repeatedly. | Prepare a weekly update. |
| Run | One recorded occurrence of a Routine. | Monday's weekly update. |

## Three distinctions that prevent mistakes

**An Agent is not a computer.** Several Agent Profiles can use a computer, and hosted agents do not require yours.

**A reply is not always completed work.** Read the result and check the requested file, change, or destination.

**A shared location changes who can see information.** Check the audience before you attach a file, copy content, or select a Routine's result destination.
