---
title: Choose an Agent
description: Choose the teammate and execution environment for your work.
---

| Choose | When it fits | Start here |
| --- | --- | --- |
| Center Agent | You want your organization’s Agent to coordinate work across Spaces and connected channels. | [Center Agent](/docs/center-agent) |
| Remote Agent | You want a named hosted teammate with its own configuration. | [Remote Agents](/docs/remote-agents) |
| Local Agent | Work needs a tool, checkout, or files on your connected computer. | [Local Agents](/docs/local-agents) |

An Agent Profile is the teammate you address. Its execution environment determines where it can run tools. A hosted Agent does not automatically have your laptop’s files or accounts.

Start with one small request and inspect the result. Use [Spaces](/docs/work/spaces) when several participants need to follow the work. See [where work runs](/docs/concepts/where-work-runs) for the underlying differences.
