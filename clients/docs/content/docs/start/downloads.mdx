## Choose what you need

| You want to… | Start here |
| --- | --- |
| Talk to Center Agent or collaborate in Spaces | [Open the web app](https://app.openmeld.ai). No download is needed. |
| Use OpenMeld in a desktop window | [Download Desktop preview](https://app.openmeld.ai/desktop). |
| Let local agents work with files on your computer | [Connect your computer](/docs/start/connect-computer). |
| Use OpenMeld from a terminal | [Use the CLI](/docs/reference/cli). |

**Desktop and OpenMeld Tools do different jobs.** Desktop gives you an app window. Tools connect your computer and carry local agent work. Signing in to Desktop alone is not proof that a local agent can run.

## Install Desktop on a Mac

The published Mac preview targets **Apple silicon**: Macs with an M-series chip.

1. Open Apple menu → **About This Mac**. Check the **Chip** field.
2. Open the [Desktop download page](https://app.openmeld.ai/desktop).
3. Choose **Mac (Apple silicon)** and download the DMG.
4. Open the DMG. Drag **OpenMeld Desktop** to **Applications**.
5. Open it from Applications and sign in with your OpenMeld account.

Use the browser on an Intel Mac unless the download page offers a compatible build.

## Install Desktop on Windows

1. Open Windows **Settings → System → About** and check **System type**.
2. Open the [Desktop download page](https://app.openmeld.ai/desktop).
3. Choose **Windows (x64)** or **Windows (ARM64)** to match your computer.
4. If a download is available, open the EXE and install it for your Windows account.
5. Open OpenMeld from the Start menu and sign in.

A platform selector does not guarantee that a build is published. If the page says the preview is unavailable, use [OpenMeld Web](https://app.openmeld.ai).

## Linux and other devices

Use the web app. The current Desktop download page does not offer a Linux installer or native mobile app. To connect a supported computer for local work, follow the platform-specific command in [computer setup](/docs/start/connect-computer).

## Check the installation

You should see your signed-in workspace. Confirm the account and workspace name before you start work.

Desktop is currently a **Preview**. Use the download page for the available version and platform status. If installation or sign-in fails, see [Desktop help](/docs/help/desktop).
