---
title: Open Terminal or PowerShell
description: Run a setup command even if you have never used a terminal.
---

A terminal is an app where you type commands. For OpenMeld setup, you only need to paste the command from your setup page and press Enter.

## Mac

1. Press **Command + Space** to open Spotlight.
2. Type **Terminal** and press Enter.
3. Copy the setup command from OpenMeld.
4. Click the Terminal window, press **Command + V**, then press Enter.

Leave the window open while setup runs. Read any prompt before answering it.

## Windows

1. Open the Start menu.
2. Search for **PowerShell** and open it.
3. Copy the **Windows** setup command from OpenMeld.
4. Paste it into PowerShell and press Enter.

Use the shell named by the setup instructions. A Mac command pasted into PowerShell will not work. Do not open an administrator terminal unless the installer specifically requires it.

## Linux

Open your distribution's Terminal app. Copy the matching command from OpenMeld, paste it, and press Enter.

## What the text means

- **A command** tells the computer what to do.
- **Output** is the text the command prints. Do not paste that output back as another command.
- **A prompt** means the terminal is waiting for your next input.
- **Command not found** means the shell cannot find the named program.

When setup finishes, return to OpenMeld and check that the intended computer is connected. If the command is not found after installation, open a new terminal window before trying again.

## Copy safely

Copy the command itself, not Markdown backticks or a leading prompt symbol such as `$`. Use the complete line. Keep setup authorization codes private.
