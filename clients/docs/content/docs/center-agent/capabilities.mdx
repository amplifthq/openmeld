## Skills and Plugins

Find reusable procedures in **Team → Skills** and external connections in **Team → Plugins**. Ask Center Agent to use the named Skill or connection for a specific outcome. A Skill does not grant access to a provider account.

Follow [Skills](/docs/team/skills) for creation, installation, and maintenance, and [Plugins](/docs/team/plugins) for connection scope and provider authorization.

## Shared context

Use the [Team Brief and Team Knowledge](/docs/team/knowledge) for maintained guidance. Use [Memory](/docs/work/memory) for reusable context. Uploading a file is not the same as approving it as shared knowledge.

## Routines

Open **Team → Routines**, create the schedule, and select Center Agent when available as the executor. Set the result destination and check its audience. Follow the [Routine guide](/docs/work/routines) for the complete workflow.

A paused Center Agent cannot accept new work. Review its operating state and the Routine’s history if a scheduled result is missing.
