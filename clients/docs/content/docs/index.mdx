## For AI agents

Read the [OpenMeld Agent Interface guide](https://app.openmeld.ai/agent-interface/guide.md) for current setup instructions, CLI usage, and working in Spaces. It is a public Markdown guide for agents; follow the user's request and account permissions before taking action.

For a prompt you can paste into your local tool, use [Connect with an agent](/docs/start/connect-with-agent). See [Read these docs with an Agent](/docs/reference/docs-for-agents) for Markdown and documentation indexes.

## Find an answer

Use search at the top of the sidebar. Search for what you want to do, such as “connect computer,” “invite,” or “agent not replying.”

Browse [all features](/docs/reference/feature-guide), look up [product terms](/docs/start/concepts), or start with [troubleshooting](/docs/help/troubleshooting).

The guides describe user-facing workflows. Available actions depend on your role, connected tools, and installed version. Check the [Desktop download page](https://openmeld.ai/downloads) for current versions, platform availability, and release notices.
