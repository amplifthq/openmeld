---
title: Routine result missing
description: Trace the Run to its destination before repeating scheduled work.
---

A saved schedule is not proof that an answer was produced. Start with the specific Run that should have produced the result.

## Find the Run

1. Open **Team → Routines** and the Routine's history.
2. Match the scheduled time and timezone to the result you expected.
3. Check the Run status and any reason shown.
4. Open **View result** if available. Check that Run's recorded destination, including its thread.

Changing the Routine's destination does not redirect an already claimed Run. Its result may belong in the previous destination.

## Choose the next action

| Status or symptom | Next action |
| --- | --- |
| Preparing or Awaiting result | Check progress. These labels do not promise a finished answer. |
| Skipped | Follow [Routine skipped](/docs/help/routine-skipped). |
| Failed | Read the failure. Check the destination and any partial artifacts before retrying. |
| Completed, but no visible answer | Check the recorded destination and your access. Keep the Run details if the answer is still missing. |
| No matching Run | Check whether the schedule is paused or finished, and confirm the time and timezone. |

## Ask for help with enough context

Include the Routine name, Run identifier if shown, scheduled time and timezone, status, visible reason, and expected destination. Share only context appropriate for the support audience.

Do not immediately create a duplicate Routine. A missing or inaccessible result does not establish that no external action occurred.
