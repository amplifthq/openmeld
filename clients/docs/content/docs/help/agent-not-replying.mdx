---
title: An Agent is not replying
description: Check the request, the Agent, and the place where the result should appear.
---

## 1. Confirm that you asked it to work

Open the original message. Check the intended Agent and its addressing mode.

**Mention only** does not start work. Adding an Agent to a Space or assigning a Task also does not prove an execution started.

If needed, send one clear request to the intended Agent. Avoid repeatedly sending the same task.

## 2. Read the current status

- **Checking** means availability is not yet known.
- **Offline** can indicate that the required local connection is unavailable.
- **Unavailable** needs the specific reason shown on that Agent.
- An active work indicator means you should inspect that work, not create a duplicate request.

Use the message on screen rather than treating all failures as the same connection problem.

## 3. For a Local Agent

Check the computer assigned to the Agent, not only the computer in front of you.

1. Make sure it is awake and connected.
2. Open its Local agents details.
3. Resolve sign-in, disabled-tool, update, or installation problems.
4. Check the selected Project and working folder.
5. Return to the Agent and check availability again.

See [Computer help](/docs/help/computer). A working Service connection alone does not prove the chosen agent tool is ready.

## 4. For a hosted Agent

Check its model, workspace access, usage, and any pause or configuration notice. Connecting your laptop does not repair hosted model or account failures.

An owner or admin may need to resume a paused Center Agent.

## 5. Check for a question or result

The Agent may be waiting for information, approval, or review. Check [Inbox](/docs/help/notifications) and the original thread.

Look for a result, an explicit failure, or a stopped outcome. Activity metadata and a recent timestamp are not completion evidence.

## Before retrying

Inspect files and external destinations for partial work. If the outcome remains unclear, record the visible error and time, then [send feedback](/docs/help/troubleshooting#ask-for-help).
