## Check these first

1. Confirm the signed-in account and workspace.
2. Read the exact message on the affected item.
3. Check the task's original conversation or result destination.
4. Follow the recovery action attached to that failure.

A connected computer, a sent message, and a completed task are different facts. Check the one that matches your problem.

## Avoid duplicate actions

Before retrying a task that sends messages, creates issues, or changes files, inspect its destination. The external action may have succeeded even if a later progress update failed.

Do not reset your account, clear local application data, or reinstall everything as a first response. Those actions can remove useful context without fixing the cause.

## Ask for help

If **Send feedback** is available, open **Settings → Personal → Send feedback**. Describe:

- What you tried to do.
- What you expected.
- What actually happened.
- The time and timezone.
- The relevant app version, platform, and visible error.

Include a permitted link to the affected item when useful. Remove setup grants, passwords, API keys, private messages, and unrelated personal information.

Sending feedback records the report. It does not guarantee an immediate reply or start an Agent automatically.
