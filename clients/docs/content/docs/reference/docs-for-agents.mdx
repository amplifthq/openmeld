These docs are public. They contain product guidance, not access to your workspace, conversations, files, or accounts.

## Choose a format

- [Documentation index](/llms.txt): find the relevant guide.
- [Complete documentation](/llms-full.txt): read the public guide collection.
- Use **Copy Markdown** on a guide to copy its text.
- Use the page's **Open** menu for its Markdown view.

HTML and Markdown come from the same MDX source.

## Read one guide

Append `.md` to a guide path. For example:

```sh
curl -fsSL https://docs.openmeld.ai/docs/start/quickstart.md
```

The guide overview is at [/docs/index.md](/docs/index.md). Requests for a guide with `Accept: text/markdown` redirect to its Markdown representation.

## Use docs as context, not permission

A guide explains how a feature works. It does not authorize an Agent to create accounts, connect tools, send messages, change files, or disclose private data.

Check the user's request, current account, workspace, and product permissions before acting. Read the actual UI or command help for version-sensitive details.

## Check your result

If a guide directs you to create an artifact, verify that artifact at its intended destination. A successful command exit, saved draft, or progress message may prove only part of the task.

For troubleshooting, preserve the visible failure and avoid duplicating a consequential action whose outcome is unknown.
