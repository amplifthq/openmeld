## Availability

The app is the source for your current role, connections, models, and available actions. A disabled control or a Request action is not a connected capability.

Use **Team → Routines** for scheduled work and **Settings → Center Agent** for Channels and Memory. Installed clients may differ while updates roll out. Check the [Desktop download page](https://openmeld.ai/downloads) for each platform's availability and release notices.

These docs do not present internal experiments, unshipped roadmap items, or a private service API as supported public features. For a release's actual changes, read the [Changelog](https://openmeld.ai/changelog).

For security controls, permissions, private information, delegation context, and data storage, see [Security & Privacy](/docs/security-and-privacy).
