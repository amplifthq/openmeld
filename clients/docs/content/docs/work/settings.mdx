---
title: Find the right setting
description: Manage personal preferences, workspace controls, and Desktop behavior.
---

Open your account menu and choose **Settings**. Check the active workspace before changing a shared setting. Personal preferences and workspace administration have different owners.

## Personal settings

| Section | What you can manage |
| --- | --- |
| Account | Your name and avatar; in the Web app, sign-in providers, password, CLI access, active sessions, and account deletion. Desktop links to the Web app for additional account controls. |
| Appearance | Theme, corner style, sidebar display, toolbar shortcuts, and Bot avatar appearance and animation. |
| Notifications | Browser or Desktop notifications, OpenMeld sounds, and urgent email alerts. The operating system or browser must also permit delivery. |
| Spaces | Send shortcut, conversation layout, message display, and conversation-list previews. Review **Automatically wake the only Agent** before enabling it. |
| Privacy & Safety | Access to your Center Agent memory, computer file-access controls, and reasoning display preferences. |

The send shortcut is saved in the current browser. **Automatically wake the only Agent** applies across your Organizations. Changing either preference affects how you send work. Check the composer before your next message. See [Messages and threads](/docs/work/messages).

## Workspace settings

| Section | Use it to… |
| --- | --- |
| Center Agent | Configure its model, identity, Team Brief, memory, Channels, and operating state. See [Configure Center Agent](/docs/work/center-agent-settings). |
| AI usage | Inspect usage by scope, period, and model. See [AI usage](/docs/team/usage). |
| General | Manage workspace identity and available lifecycle actions. |
| Members | Review people and manage Organization roles. |
| Invitations | Manage invitations and review requests and history. |
| Security | Manage Organization information-protection hints. |

Organization controls depend on your role. A Personal Workspace does not have shared membership or Organization security administration. See [Workspaces and members](/docs/team/workspaces).

## Desktop settings

The Desktop app also has **Desktop** and **Updates** sections. Use **Open at login** for startup. Where available, **Start in background** controls whether startup opens a visible window. Use Updates to inspect the installed release and available update actions.

These controls do not connect a second computer or repair a local tool's provider login. Use [Computer connection help](/docs/help/computer) for those problems.

## Confirm a change

Wait for the control's saved state or success message. If a save fails, resolve the displayed error before leaving. A missing control can reflect your role, workspace type, or host; it does not always indicate a broken page.

See [Security & Privacy](/docs/security-and-privacy) for permissions, private information, task context, and data storage.
