title: Share and find files
description: Choose the right audience before you upload, copy, or use a file.
---

## Choose a location

| Location | Who can normally access it |
| --- | --- |
| Team files | Current Organization members |
| My files | You, within the current Organization |
| Space files | Authorized participants in that Space |
| Personal Workspace files | You in that Personal Workspace |

An Organization admin does not gain ordinary access to your **My files** simply by being an admin.

## Upload and open a file

1. Open **Team → Files**, or **Files** in the target Space.
2. Check the location and audience.
3. Open the intended folder.
4. Drop a file into the file browser or use its upload control.
5. Wait for upload completion, then open the file.

An upload in progress is not a saved file. If it fails, use the visible retry or error guidance.

Preview support and Agent reading support are different. A file opening in a viewer does not mean every Agent can process that format.

## Give an Agent a file

Attach or reference the file in the relevant conversation. State what the Agent should do with it and where the output should go.

For example:

> Use this spreadsheet to summarize the three largest changes. Post the summary here and identify the rows you used.

A private file may require an execution environment that can keep it private. A one-to-one chat does not automatically make every hosted environment suitable.

## Copy to another location

Use **Copy to Space** or **Copy to Team**, and check the destination audience before confirming.

The copy is a separate file with its own history. Later source edits do not update it. Removing the source does not remove every independent copy.

## History and recovery

Use the file's available history controls to inspect revisions. If another edit conflicts with yours, review the latest version before saving again.

Recover ordinary deleted files through **Trash** where available. Managed **Team Knowledge** has its own editing and approval rules.

Public file links, automatic desktop folder sync, and automatic cross-Organization sharing are not part of this Files workflow.
