---
title: Work with Center Agent
description: Ask for an outcome, provide context, and keep the work in one conversation.
---

Center Agent is the hosted AI teammate for your current workspace. It can answer questions, help organize work, and use the capabilities available to the person making the request.

## Start a conversation

1. Open **Center Agent** from the bottom toolbar.
2. Open the full chat if you need its history, files, or other views.
3. Write the result you want. Add the information needed to produce it.
4. Read the reply, check the result, and continue in the same conversation.

Start a new conversation for unrelated work. Switching conversations changes the discussion context; it does not create another Center Agent.

## Write a useful request

Include the source, output, and limits. For example:

> Use the notes below to draft a customer update. Keep it under 150 words. Separate shipped changes from planned work. Save the draft here; do not email it.

For work in another app, name the account or repository and what the Agent may change. If a required connection is missing, [connect the Plugin](/docs/team/plugins) before expecting that action to work.

## Follow work and respond

Read progress and any request for information or approval. A question from the Agent may be the next required step.

Use the conversation's available stop control when you want work to stop. Check the resulting state. A click alone does not prove an external operation was canceled.

## Review the outcome

Check that a claimed file exists, a draft contains the right facts, or a change appears at its stated destination. Ask for the source when a factual claim matters.

Use **Files** for artifacts attached to the conversation. **Graph** offers a visual view of the conversation's work. Neither replaces the actual result.

## Suggestions and memory

Center Agent may suggest an improvement during a conversation. You can accept, defer, or dismiss it. Accepting a suggestion does not, by itself, authorize every action needed to implement it.

[Memory](/docs/work/memory), [Skills](/docs/team/skills), and [shared knowledge](/docs/team/knowledge) supply different kinds of reusable context.

If an owner or admin pauses Center Agent, work may be unavailable until it is resumed in Center Agent settings.
