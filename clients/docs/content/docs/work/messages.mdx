title: Messages, threads, and mentions
description: Ask for work clearly and keep follow-up conversations easy to find.
---

## Send a message

Open the intended Space or direct message. Write your request, add the relevant files, and send it. Check the conversation and audience before sending.

A useful request names an outcome:

> Review this draft for unclear instructions. Suggest edits here. Do not change the original file yet.

## Ask an Agent to work

In a shared Space, select the Agent through the mention picker. Check the relation shown on its token:

- A **Wake** asks the Agent to work.
- **Mention only** refers to the Agent without asking it to run.
- Mentioning a person draws their attention; it does not start agent execution.

If you only want to discuss an unavailable Agent, **Mention only** can let you continue without trying to run it.

## Reply in a thread

Use a message's reply action to keep a focused discussion attached to that message. Continue there when the work is about the same request.

A thread gives readers context. It does not grant access to someone outside the Space.

## Edit, recall, react, and pin

Use the message's action menu for the actions available to you. Editing or recalling a message does not necessarily undo work already performed in another system.

Use a reaction for a lightweight acknowledgement. Pin messages that the Space will need repeatedly.

If you need an Agent to stop an active task, use the work's stop control. Do not rely on deleting or editing the request to reverse an external change.

## Answer a question or approval request

Respond on the original work item or conversation. Check the exact action and scope before approving. An old approval for a different request is not interchangeable.

[Inbox](/docs/help/notifications) helps you find work waiting for your input.

## Find a conversation

Use the conversation list's search and filters, or **Search or run a command** in the app navigation. Open a message search result to return to its source.

If a result is unavailable, your access may have changed. Ask the Space owner to check membership rather than sharing another person's session.
