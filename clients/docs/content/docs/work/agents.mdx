---
title: Create and use an Agent
description: Choose a hosted teammate or an agent that runs on a connected computer.
---

An Agent Profile is the named teammate you see in conversations. Its settings choose how and where it works.

## Choose Local or Remote

| Type | What you need | Where work runs |
| --- | --- | --- |
| Local | A connected computer, an available agent tool, and the intended working folder | On that computer |
| Remote | An available hosted model and permission to create the Agent | In OpenMeld's hosted environment |
| Center Agent | Your workspace's managed Center Agent | Hosted by OpenMeld |

Remote does not mean the Agent can automatically read files from your laptop. [Share the required files](/docs/work/files) or connect the required tool.

## Create an Agent

1. Open **Team → Agents**.
2. Use the creation action and choose **Local** or **Remote**.
3. For Local, select the computer and agent tool. Complete any connection or sign-in action shown.
4. Select the available model and settings.
5. Check the proposed name, or enter a name that helps your team recognize the Agent.
6. Save and inspect its current availability.

For a Local Agent, check the working folder or Default Project before sending a task that reads or changes files. A folder path on one computer is not a folder on another.

## Give it work

Open a direct message or add the Agent to a [Space](/docs/work/spaces). Send a clear request. In a shared conversation, select the intended Agent and keep the addressing mode set to ask it to work.

**Mention only** adds a reference without starting work.

Try a bounded first request:

```text
Read the notes attached to this message.
List three open questions and quote the note behind each one.
Reply here. Do not edit files or contact anyone.
```

Check the actual reply and its sources before assigning a larger task. For repository work, follow [Ask a Local Agent to review code](/docs/tasks/local-code).

## Change settings carefully

The Agent's owner manages its execution settings. Model and permission choices depend on the selected tool and available account. A more permissive mode can allow more actions; choose it deliberately.

Changing the Agent's name does not change the computer or tool that runs it. After changing execution settings, check availability again.

## When it cannot reply

Use the reason shown on that Agent. Local recovery may involve its computer, tool sign-in, or folder. A hosted Agent's failure is not fixed by connecting your laptop.

See [Agent not replying](/docs/help/agent-not-replying).

If the reason names a Project or folder, use [Working folder unavailable](/docs/help/working-folder). For the difference between the teammate and its execution environment, see [Where work runs](/docs/concepts/where-work-runs).
